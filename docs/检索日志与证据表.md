**机理归类（供建模选型）**

- 被动式：悬臂 + 拉/压/扭簧（P1）。接触顺序由几何与弹簧力矩决定，无额外驱动自由度；适合作为首版模型的简化悬挂。

- 混合式：浮动清洁头抬升（P5）不改变主驱动轮接地，单独建模为随动质量即可。

## 4. MuJoCo 建模与输出方法证据（清单第 5 项）

权威来源：[MuJoCo Computation](https://mujoco.readthedocs.io/en/stable/computation.html)（访问日 2026-11-21；站点当时只写 stable、未钉版本号，见本节末“版本说明”）；参数定义另见 [MJCF XML Reference](https://mujoco.readthedocs.io/en/stable/XMLreference.html)（本轮未逐条抓取，留待建模型时按实际版本核对）。

| 主题 | 官方结论（摘要） | 对本项目的落地方式 |
| --- | --- | --- |
| 接触模型 | MuJoCo 用连续时间软约束/凸优化，**不是**严格 LCP 互补；"for soft contacts complementarity has to be violated"。软接触由弹簧阻尼垫近似，力连续可微。 | 接触参数是待标定的模型参数，不是可直接测的物理量；与实体测量参数分开登记 |
| `condim` | 只能是 1/3/4/6（不能 2 或 5，成对处理）。1=无摩擦仅法向；3=法向+切向滑动摩擦（椭圆锥下 3 维、金字塔锥下 4 维）；4=加绕法线扭转摩擦（扭转系数单位为长度，可理解为接触斑直径）；6=加滚动摩擦（系数单位亦为长度，可理解为接触区变形深度；可用于轮胎-路面、阻止球无限滚动）。两 geom 自动配对时取较大 condim。 | 车轮-地面建议 condim=3 起步；若需抑制伪滚动/自旋再评估 4/6（注意系数单位变为长度） |
| `friction` | 维度 = condim−1，分别为滑动、扭转、滚动系数；椭圆锥下摩擦锥 `f1^2 >= Σ(f_i/μ_{i-1})^2`；金字塔锥为盒约束二次规划。锥型由 `option` 的 `cone` 决定（`pyramidal` / `elliptic`），**与求解器无关**；4.0.1 默认 `pyramidal`，`condim=3` 时给出 4 行棱边系数（每行约为法向力的 1/4），显式设 `cone="elliptic"` 才得到 3 行、首项即法向力；PGS / CG / Newton 在 4.0.1 下都能使用椭圆锥（实测）。 | 橡胶-硬地滑动系数按工程经验 0.6～1.0 起步（见下文经验来源），必须标定；斜向接近建议用椭圆锥 + pair 分轴各向异性 |
| `margin` / `gap` | distance > margin+gap 无接触；margin<distance≤margin+gap 为非活动接触（`efc_address=-1`，无力）；distance≤margin 为活动接触。负值 margin（缩水）允许，但须保持 margin+gap≥0。 | 用 gap 做接触预检测、用 margin 控制接触触发距离；不要把 margin 当物理间隙 |
| `solref` / `solimp` | 官方文档本轮抓取片段给出：时间常数与阻尼比需与步长相容；`discrete` 积分器下 `timeconst × dampratio ≥ h` 的约束行按原样保留，否则可能在冲击时反弹（可用 refsafe 处理）；阻抗上限为 mjMAXIMP。完整字段定义不在本次抓取片段中。 | 工程经验值（见下）：`solref ≈ [0.01–0.02, 1]`（时间常数 ≥ 2×timestep），`solimp ≈ [0.9–0.99, 0.999, 0.001–0.003, 0.5, …]`；软地面调大 dmax。**须按实际 MuJoCo 版本复核 solimp 五参数的顺序与含义** |
| 时间步与积分器 | "time step is perhaps the single most important parameter"；过小浪费算力、过大不稳，取值模型相关。`implicitfast` 为官方推荐（多数模型，与 Euler 成本相近、稳定性更好），但 4.0.1 的引擎默认仍是 `Euler`（实测）；`implicit` 适合强耦合旋转系统（含科氏/向心力，如滚动椭球）：`Euler` 主要为兼容旧模型；`RK4` 适合近能量守恒系统；`discrete`（2026-09 新增、仍在开发）适用于硬弹簧/位置伺服/强阻尼与接触耦合的情形，且 `qacc` 报告的是有限差分速度步而非连续加速度。 | 首版用 `implicitfast`；门槛冲击若出现数值抖动，先做 timestep 敏感性检查（如 0.002 / 0.001 / 0.0005 s），再考虑 `implicit`；记录所用版本 |
| 求解器 | Newton、CG 用简约原始形式；PGS 用对偶形式（金字塔锥为盒约束 QP，椭圆锥混有二阶锥）。典型机器人模型 10 次 PGS 扫描与全局最优实际不可区分；CG 用 Hager-Zhang 非线性共轭梯度、精确线搜索。逆动力学解析求解，不需迭代。 | 优先默认 Newton/CG；用接触力残差与能量漂移判断收敛是否充分 |
| 输出量 | 约束/接触力在 `mjData.efc_force`，按每个 contact 的 `efc_address` 索引；活动接触 `efc_address!=-1`。接触雅可比 `E^T S` 插入系统级 J，`J^T f` 映射到关节坐标。椭圆锥下 f 的前三分量为接触系力、后三分量为力矩；金字塔锥下为棱边非负系数。 | 轮速/机身姿态从 `qvel`/`qpos` 取；轮端扭矩由执行器力矩与关节约束力矩核对；接触力按 `efc_address` + condim + 锥型解码（金字塔锥下 `efc_force` 是棱边非负系数、不是物理力，真实施加力用 `mj_contactForce`，法向 = 各棱边系数之和）；统一在固定频率采样并做时间步敏感性检查 |
| 执行器出力限制 | 官方文档本轮抓取片段未含执行器章节。 | 建模型时按实际版本核对 `actuator` 的 `forcerange`、`ctrlrange`、`gear`、`gainprm`/`biasprm`，并与电机规格（堵转扭矩、限流）对应；从电机端换算到轮端须保留减速比与效率 |

**版本说明（追溯缺口与复核范围）**：Phase 1 抓取 MuJoCo 文档时只记录了 "stable"，没有钉版本号，而 4.0.0 是破坏性大版本。复核日（2026-11-21）站点 stable = 4.0.1，本节 `condim`、`friction` / 接触锥、输出量三项已按 4.0.1 在 Windows 实测（见 [仿真环境安装与版本](仿真环境安装与版本.md)）；`solref` / `solimp`、积分器语义与执行器限幅仍待按 4.0.1 逐条复核，未复核项不得当作已验证结论使用。
