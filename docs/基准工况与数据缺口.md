# 扫地机器人越障动力学仿真｜基准工况与数据缺口

- 编制日期：2026-11-21
- 配套文档：[检索日志与证据表](检索日志与证据表.md)、[仿真参数表](仿真参数表.md)
- 工况定义遵循 [资料检索清单](越障动力学资料检索清单.md)：硬质门槛或单级台阶首轮工况，含正向与斜向接近，平地行驶作对照；软地毯边缘与多级门槛列为后续扩展。

## 通用定义

**通过判据（建议，待项目确认）**

1. 主判据：整机跨过障碍、全部车轮重新落在障碍后方的同一平面上，并恢复前进 ≥ 1 个车身长度（或恢复至接近障碍前的稳态速度带）。
2. 失败记录（即使跨过也单独标记）：打滑（左右轮速与机身速度不一致）、悬挂触底/限位撞击、底盘托底（机身最低点接触障碍顶边或棱边）、失速（轮速指令存在但机身速度近零持续超过阈值）、退回（质心沿前进方向净位移为负）、倾覆（横滚/俯仰超过稳定边界）。
3. 理论约束（来自 D1 / D9）：任一接地轮法向力 > 0（保持接触）；牵引力/法向力 < μ（不打滑）。当约束被破坏时，即使几何上越过后方平面也判为未通过。

**统一输出量（所有工况都记录）**

| 类别 | 量 | 采样/处理要求 |
| --- | --- | --- |
| 机身 | 位置、速度、俯仰角 pitch、横滚角 roll、偏航角 yaw | 与 PTS 对照时 ≥ 30 Hz（IEC 62849 §4.7） |
| 轮系 | 左右轮速、轮速差、滑移率、轮端扭矩、电机电流 | 轮端与电机端标注清楚；保留减速比与效率 |
| 悬挂 | 轮心相对机身行程、限位撞击标记、弹簧力 | 如为主动抬升则记录抬升指令与实际位移 |
| 接触 | 各轮-地/轮-门槛接触力（法向+切向）、接触点位置 | 按 `efc_address` 解码；注意 condim 与锥型 |
| 底盘 | 最小离地间隙时程、托底标记 | 机体最低点与门槛几何的距离 |
| 结果 | 通过/失败、爬升耗时、越障前后速度、能耗增量 | 与试验报告字段对齐 |
| 数值 | 时间步、积分器、求解器、接触参数、MuJoCo 版本 | 每次运行记录，支持复现 |

## 工况 A：平地行驶（对照组）

| 项目 | 内容 |
| --- | --- |
| 输入 | 平坦硬地（未处理层压松木板或等效，厚 ≥ 15 mm，IEC 62849 §6.1.2.1）；起始朝向按标准 "start orientation"；速度取机型正常清扫速度（**本机值缺失**）；无门槛 |
| 通过判据 | 直线行驶不跑偏、轮速与车身速度一致、无异常俯仰/横滚、无打滑 |
| 可对比输出 | 稳态轮速、滑移率、机身 pitch/roll 波动、电机电流基线、接触力基线、能耗（作为越障能耗增量基线） |
| 已有证据 | 测试床与环境条件来自 IEC 62849:2025；摩擦/接触参数区间来自调参经验来源；MuJoCo 输出方法来自官方文档 |
| 缺口 | 本机质量/质心/轮径/轮距、正常清扫速度、目标摩擦系数实测值、轮速传感器与 PTS 的对照数据 |
| 用途 | 标定摩擦与基线能耗；验证仿真在无障碍时复现真实速度-电流关系 |

## 工况 B：正向硬质门槛（主工况）

| 项目 | 内容 |
| --- | --- |
| 输入 | 三类门槛（IEC 62849 Table 3）：圆柱（半径可变）、矩形（宽 40 mm、顶边 R3 mm、高度可变）、梯形（顶边 40 mm、底角 40°）；铝制未处理表面、长度 ≥ 2150 mm、固定；高度从 10 mm 起按 5 mm 递增至失效；起始朝向正对门槛（ψ=0°）；速度按机型正常行进速度 |
| 通过判据 | 通用判据 1～3；额外关注接触顺序（哪只轮先触棱边）、悬挂是否触底、底盘是否托底 |
| 可对比输出 | 最大通过高度、各高度下通过率、爬升耗时、pitch 峰值、悬挂行程峰值、轮端扭矩峰值与电流曲线、接触力时程、打滑率、托底/退回标记 |
| 已有证据 | IEC 62849:2025 §6.1.2（台架与门槛几何）；D1（150 mm 台阶、10 m/min、电机电流与扭矩趋势一致）；D2（h≤R 判据、方程组 14/15）；D3（台阶需小于轮半径）；D5（前轮绕棱→中段→后轮绕棱三阶段模型）；D6（台阶竖直面处水平速度降为零、摩擦 0.3）；P6（标称 3/4 cm，但无曲线） |
| 缺口 | IEC 62849 §6.1.3 测试方法正文（助跑距离、重复次数、通过判定原文）；本机悬挂形式与各参数；轮端扭矩上限；标准化实测曲线（高度-通过率、pitch/扭矩时程） |
| 用途 | 首版模型的主校准工况；判据与 D1/D2/D5 直接对应 |

## 工况 C：斜向硬质门槛

| 项目 | 内容 |
| --- | --- |
| 输入 | 同工况 B 的门槛几何；航向与门槛法线夹角 ψ 建议取 15°、30°（**本机试验角度待定**）；记录左右轮接触时刻差；正/负角度各做一组以覆盖左右不对称 |
| 通过判据 | 通用判据 1～3；额外关注：单侧先接触后是否产生偏航、是否因左右轮速差导致横滚超限、是否出现"一侧爬上另一侧卡住" |
| 可对比输出 | 左右轮接触时间差、yaw 变化、roll 峰值、左右轮速差与扭矩差、质心轨迹偏移、通过率随 ψ 的变化 |
| 已有证据 | D7（斜向进入时左轮先接触并保持 roll=0° 爬升，右轮随后遇台阶；载荷分配阈值 k_d1=0.65、k_d2=0.60）；D8（摇臂转向架非垂直接近或单侧遇台阶仍可通过）；D1（所需摩擦系数可衡量斜向附加需求）；MuJoCo 官方（椭圆锥 + 各向异性摩擦适合切向敏感场景） |
| 缺口 | 斜向角度序列与重复次数；有无"先接触侧通过后另一侧失速"的实测视频/曲线；各向异性摩擦实测值 |
| 用途 | 验证接触求解器与横向摩擦模型的鲁棒性；斜向是首版最可能暴露建模缺陷的工况 |

## 本机补测清单

### A. 用于标定的试验（调模型参数）

1. 静态几何与质量：整机称重、质心（悬挂法）、惯量（摆动法）、轮径/轮距/离地间隙、悬挂行程与限位角。
2. 悬挂特性：弹簧力-位移曲线、阻尼阶跃响应、限位撞击恢复。
3. 摩擦：轮-地板、轮-门槛（两种表面）滑动摩擦，干态、固定温湿度（23±5 °C、45±15 %RH）。
4. 驱动：扭矩-转速-电流曲线、堵转扭矩与限流、轮端实际输出（减速比与效率核对）。
5. 平地基线与正向门槛：按 IEC 62849 台架，门槛高度 5 mm 递增，每高度 ≥ 3 台样品、重复次数按标准全文执行；采集通用输出量全部字段。
6. 时步/求解器敏感性：同一工况下 h = 0.002/0.001/0.0005 s 对照，记录接触力峰值与通过结果差异。

### B. 用于独立验证的试验（不参与标定）

1. 斜向门槛：ψ = 15°、30°，正/负角度各一组；左右轮接触时序与时程输出。
2. 未参与标定的门槛高度（如标定用 10/20/30 mm，验证用 25/35 mm）与第三种门槛形状。
3. 助跑工况（若有）：不同起始距离下的通过高度与爬升耗时。
4. 厂商标称高度对照：在标准台架上复现标称 3/4 cm 条件，检验标称值的可重复性（当前仅有 heise 现场观察，无仪器数据）。

## 交接建议

- 最影响首版模型可信度的输入依次为：**本机机构形式 → 质量/质心/惯量 → 轮径轮距 → 悬挂参数 → 轮端扭矩 → 摩擦系数**。前三项缺失时不宜给出定量通过高度结论，只能给出机理与参数敏感性分析。
- 应立即启动的动作：确认目标机型并落实图纸/CAD；采购或加工 IEC 62849 门槛模块与标准测试床；获取 IEC 62849:2025 全文第 6.1.3 条。
- 仿真环境尚未安装（上一阶段仅完成仓库与同步初始化）。安装时按 [AGENTS.md](../AGENTS.md) 与 README 约定：Windows 端 `E:\mujoco-robot-vacuum`、`.venv/`、项目内锁文件与 Skill，版本升级随锁文件和验证记录一起提交。
