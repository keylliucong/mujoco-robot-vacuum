# OOMWOO 基准机型：缺口与影响

- 编制日期：2026-11-22
- 配套：[oomwoo-参数提取](oomwoo-参数提取.md)、[驱动轮组件 STEP 尺寸表](oomwoo-drive-wheel-dimensions.md)
- 结论等级口径：G2 契约 §4（分支 `contract/g2-interface`）与 ADR-012：**参数行等级只看 `label`，结论等级 = 参数标签且容差刻度**。本文只讨论“来源”对结论等级的影响，不讨论 `verified_tol` 数值。

## 0. 一句话

OOMWOO 基准**没有完整填掉任何一个 P0**：CAD 只到 URDF 参数化外形 + `lib/` 零件 STEP（`stock/` 整机 CAD 在当前 rev 缺失）；质量/质心/惯量只有 URDF 占位值；悬挂只有结构形式；轮端扭矩只有减速比/编码器/电机电气，扭矩未实测。它能把这四类从“完全空白”推进到“可做敏感性分析的公开参考/图纸推算”，但**整机结论仍封顶 `mechanism`**。

## 3. 结论等级影响

### 3.1 规则

按 G2 契约 §4（分支 `contract/g2-interface`）与 ADR-012：

- 决定性参数全为【本机实测】**且**该比对所需的 `verified_tol` 齐备 → `quantitative`；
- 含【图纸推算】/【公开参考】/【工程假设】→ 封顶 `sensitivity`；
- 含【缺失】/【待标定】→ `mechanism`。

OOMWOO 是**另一台机器**：即使它的某个值是作者实测，对我们也只是【公开参考】。所以 OOMWOO 基准**永远不能**把我们的整机结论推到 `quantitative`；它最多把某些只依赖公开几何/零件数据的子分析从“没有输入”推到 `sensitivity`。

### 3.2 能从“机理”升到“敏感性”的结论

| 结论 | 现在可到的等级 | 依据 | 限制 |
|---|---|---|---|
| 几何通过性量级（h/R、轮径/轴距/轮距的几何筛查） | `sensitivity` | URDF 349/68/235/144.5；lib STEP 71.61；IKsares 71.5 | 轮径有 68/71.61/71.5/65 四个值，只能给区间；离地间隙/最低点不完整 |
| 轮速—车速/编码器换算 | `sensitivity` | 65.36:1、4 cycles/电机转、261.5 edges/轮转、0.859 mm/edge | 单通道无方向；另一套 ~228 PPR 差 ~13%；不是本机轮 |
| 轮端扭矩量级/牵引力上界 | `sensitivity` | R=5.08 Ω、V0=1.91 V、堵转 1.99–2.93 A、空载 6,165 rpm、65.36:1 | 扭矩未实测；η=0.6–0.8 是假设；与 URDF 0.5 冲突；只能给区间 |
| 从动轮/支撑多边形的几何检查 | `sensitivity` | 从动轮 25 mm、轴距 144.5 mm、轮距 235 mm | 从动轮实际接触点/摆角未给；悬挂行程缺失 |

示例（只说明量级，不是通过结论）：h=10/20/30/40 mm 对 R=34 mm 得 h/R=0.29/0.59/0.88/1.18；对 R=35.80 mm 得 0.28/0.56/0.84/1.12。这是几何敏感性，不能当“能过/不能过”。

### 3.3 仍只能“机理”的结论

| 结论 | 为什么仍 `mechanism` |
|---|---|
| 定量通过高度 / 通过率曲线 | 缺本机质量/质心/惯量、悬挂、轮端扭矩、摩擦；OOMWOO 不能替本机 |
| 载荷转移 / 各轮法向力 / 牵引裕度 | 缺本机质量/质心/惯量；URDF 质量是占位，CoM 只有 x |
| 悬挂触底 / 底盘托底时程 | 缺行程、刚度、预压、阻尼、限位；URDF 没有悬挂自由度 |
| 失速 / 限扭判定 | 轮端扭矩只有区间/冲突；限流、效率缺失；`0.5 N·m` 来源不明 |
| 斜向横滚 / 偏航 / 左右接触时序 | 缺本机 CoM/惯量/悬挂；OOMWOO 的轮距/轴距不是本机 |
| 轮-地/轮-门槛摩擦与打滑 | OOMWOO 没有摩擦实测；Gazebo 默认值不可当 OOMWOO 实测 |

### 3.4 对整机结论等级的净影响

- **整机**：仍是 `mechanism`。因为它必然包含我们本机的【缺失】（质量/质心/惯量/悬挂/摩擦）和【待标定】（接触参数）。OOMWOO 只能替换其中一小部分“空白”，不能消掉这些洞。
- **子分析**：h/R 几何筛查、轮速换算、轮端扭矩量级、支撑多边形几何检查可以从“机理”升到 `sensitivity`，前提是报告里明确写“这是 OOMWOO 公开参考/图纸推算，不是本机实测”，并把冲突值作为区间。
- **不能升级的**：任何需要本机质量/质心/惯量/悬挂/摩擦的结论，仍只能 `mechanism`。

## 4. 来源可信度分级（三档，不能混）

| 档 | 来源 | 标签 | 可用性 | 为什么 |
|---|---|---|---|---|
| **1. 文档 / BOM / URDF / part-specs** | `oomwoo@0218857` 的 `BOM.md`、`docs/*.md`、`contributions/part-specs/*`；`oomwoo-one@a630d1c` 的 `urdf/*` | 【公开参考】 | 可作设计阶段参考；不能当量产实测 | 项目仍是设计/RFC 阶段（`oomwoo@0218857:README.md:20`、`docs/BUILD_INSTRUCTIONS.md:3-8`）；URDF 自称近似；part-specs 有实测也有推算，逐条看作者标注 |
| **2. `lib/` + `stock/` 可信 CAD** | `oomwoo-cad@266210a` 的 `lib/`（3D 扫描/采购件 STEP）；`designs/one/stock/`（若存在） | 【图纸推算】 | 可作组件级几何/质量属性，须带 S17 血缘 | `lib/` 是作者/贡献者扫描或采购件模型，接口尺寸可信度高；本次用了 `lib/roborock/OOM-W01-drive-wheel-assembly.stp` 的轮体，轮径 71.61 mm 与 IKsares 卡尺 71.5 mm 互证。**但 `designs/one/stock/` 在当前 rev 没有文件**，所以没有可信整机 CAD；Fusion 归档未解析。驱动轮 STEP 读入时还有 `Unresolved Reference` 1 处，轮体完整但整模块质量/惯量在修好前不要用（见尺寸表 `input_warning`） |
| **3. `designs/one/agentic/july-2026/` 实验件** | `device_full.step` 及其同名 png/pdf | **不可用；不要引用** | 禁止混入第 2 档 | 该目录 README 自己写 “This is **not** the OOMWOO One design”，是未评审的 pipeline 输出，并列出已知设计错误：**万向轮倒装**、风机与主刷分处两侧、侧刷装反、保险杠装在筒身外。万向轮倒装会直接改支撑多边形，风机位置错会直接改质心；用它算出的质量/质心/惯量会“错得很像对的” |

### 4.1 一条要写进报告的教训

**“有 STEP、有报告”不等于“可信”。** 一个文件长得像几何、能被 CAD 内核打开、能算出漂亮的体积/惯量，不代表它是设计：拓扑有效、尺寸看着合理，和“装配意图正确”是两件事。第 3 档的危险恰在于它**在数值上很完整**——如果只看“有整机 STEP”，会把它当整机 CAD；一旦它的万向轮倒装/风机错位进入质量属性，支撑多边形和质心会静默偏掉，而所有检查都“通过”。

所以：

- 第 3 档不能混进第 2 档；只来自第 3 档的值，标签是【缺失】，不是【图纸推算】。
- 第 2 档也要逐件看：`lib/` 的组件 STEP 可以推组件几何；`stock/` 整机 STEP 才能推整机质量/质心/惯量。**组件级不能冒充整机级。**
- 第 1 档的“实测”是作者在别的机器/别的批次上测的；对我们仍是【公开参考】。

**另一个同类的坑（URDF 不是 CAD）**：`oomwoo-one` 的 `urdf/inertial.xacro:14-20` 给圆柱惯量加了 `rpy="pi/2 0 0"`，而 visual/collision 的 `<cylinder>` 轴是 link z；两者差 90°。并且 `base_link` 的圆柱中心在 `z=33.25 mm`，inertial origin 却在 link 原点（车体底面），2.5 kg 筒身的 CoM 被放在地面以上 12.5 mm，而不是 45.75 mm。**有 URDF、有 `<inertial>` 不等于有可用惯量**；URDF 的总质量可以求和，但整机 CoM z / 惯量不能直接拿来用。

## 5. EXCLUDED：不得用 oomwoo 的值补本机型的空

> **EXCLUDED**：OOMWOO 的 349 mm、2.937 kg、0.5 N·m、65.36:1、71.61 mm 等值，只能作为基准机型的【公开参考】/【图纸推算】。**不得**写进本机型参数表当【本机实测】，不得用它们填本机 P0 的空，也不得用它们把本机结论从 `mechanism` 直接推到 `quantitative`。本机结论仍需本机 CAD、称重、质心/惯量试验、悬挂试验、测功机和摩擦试验。

## 6. 每个 P0 要补什么

| P0 | 最小补测/补资料 | 能把结论推到哪 |
|---|---|---|
| CAD / 整机几何 | 评审通过的整机 CAD/STEP（含材料/公差）；或本机卡尺 + 三坐标；至少确认轮径、轮距、轴距、最低点 | 几何子分析可到 `sensitivity`；有本机实测后才可能 `quantitative` |
| 质量/质心/惯量 | 整机称重；三点/悬挂法测 CoM；三线摆/扭摆测惯量（优先过质心轴，`d ≤ 5 mm`）；或材料赋值 CAD + 称重互校 | 载荷转移/法向力子分析可到 `sensitivity`；有 `verified_tol` 后才可能 `quantitative` |
| 悬挂 | 拆驱动轮模块：行程、弹簧力-位移、预压、阻尼（阶跃/落锤）、限位/止挡 | 悬挂触底/托底子分析可到 `sensitivity` |
| 轮端扭矩 | 测功机测 T(ω)、堵转、电流；或电机规格书 + 减速器效率 + 限流实测；确认 `0.5 N·m` 的来源 | 失速/限扭子分析可到 `sensitivity` |

## 7. 最该先看的三条

1. **没有可信整机 CAD**：`designs/one/stock/` 在当前 rev 缺失；唯一“整机 STEP”是明确写着“不是设计、有已知错误”的 agentic 实验件，不能用。URDF 虽然有 `<inertial>`，但圆柱宏的 rpy/原点与视觉几何不一致，不能直接算整机惯量。整机质量/质心/惯量因此仍是【缺失】，不是“算不出来”，是“没有可信输入”。
2. **驱动轮模块是这批资料里最强的一组**：65.36:1 齿数实测、4 对极编码器、R=5.08 Ω、V0=1.91 V、堵转 1.99–2.93 A、lib STEP 轮径 71.61 mm 与卡尺 71.5 mm 互证；推算轮端堵转 1.14–2.80 N·m，和 URDF 的 0.5 N·m 冲突。它足够给 A4 一个敏感性区间，但不够定标。
3. **悬挂是最大的洞**：结构形式知道（模块内置被动摆臂+弹簧），但行程、刚度、预压、阻尼、限位全无，URDF 也没有悬挂自由度。任何“悬挂触底/底盘托底”的结论都只能停在 `mechanism`。
