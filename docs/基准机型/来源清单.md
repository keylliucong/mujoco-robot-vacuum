## 抄录约定（oomwoo-one-params.csv）

- 一行一个 `xacro:property`，共 76 行（含跨行的 `camera_vfov_deg`，记为 `params.xacro:169-170`）。
- 列顺序：`param_id, value, unit, 含义, 文件路径:行号, 原始变量名, unit_as_written`。
- `value` 为 `value` 属性**逐字照抄**（含 `${...}` 表达式）；不换算、不推断、不展开公式。
- `unit` 与 `unit_as_written` 只取文件中**明确写出**的单位：优先行内注释、段注释，其次 `params.xacro:4` 的文件级 Units 声明；文件未给单位的（如采样数、像素尺寸、`DEG2RAD`）写 `未找到`。
- `含义` 取文件自带注释；无注释时按变量名标注 `（文件无注释；按变量名）`，不补造数值或条件。
- `文件路径:行号` 一律带行号；`param_id` 采用 `oomwoo_one__<原始变量名>`，便于台账去重。
