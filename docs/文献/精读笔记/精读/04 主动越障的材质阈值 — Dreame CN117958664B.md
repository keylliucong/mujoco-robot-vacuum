# 标称 4–5 cm 不是被动能力：被动 3 cm + 主动 1–2 cm

**论文**：熊程刚，追觅创新科技（苏州）有限公司，*一种清洁机器人的主动越障控制方法、系统及清洁机器人*, CN117958664B, 2024。[Google Patents](https://patents.google.com/patent/CN117958664B/zh)；[Zotero](zotero://select/library/items/UDMIMZZP)。无 DOI。

**已阅读范围**：仅按清单定位到摘要与实施例一、图 3/5、材质区间段，未通读；数值均为实施例示例。

## 核心结论与研究设计

清单把这篇当作“被动能过多少”与“主动抬升能多多少”的具体数字：被动极限 3 cm，主动增加 1–2 cm，达 4–5 cm。

- 主动机构：接触点距驱动轮接地点 3–5 cm，靠杠杆抬升。[摘要、实施例一]
- 触发逻辑：先识别障碍高度与接触面材质，落在该材质的预设越障高度区间内才开启主动越障。[摘要]
- 材质区间：木材 3–5 cm、瓷砖 2.5–4.5 cm、地毯 3.5–5.5 cm。[材质区间段]
- 地毯修正：下陷量 H2，实际越障高度按 H1+H2 计算。[图 3/5]

## 项目应用

- 设计主动抬升时，按“执行器/限位/触发逻辑”三块拆，接触点距接地点 3–5 cm 作为起点。
- 报告里解释为什么厂商标称 4–5 cm 不能与被动 2–3 cm 直接比较。
- 若做材质相关阈值，把木材/瓷砖/地毯三档写进参数表并标“实施例值”。
