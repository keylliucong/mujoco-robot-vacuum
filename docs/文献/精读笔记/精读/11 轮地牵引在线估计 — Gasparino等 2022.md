# 用轨迹反推轮地牵引：μ、ν 接近 0 就是卡住

**论文**：Gasparino, Sivakumar, Liu, Baquero Velasquez, Higuti, Rogers, Tran, Chowdhary, *WayFAST: Navigation With Predictive Traversability in the Field*, IEEE RA-L 7(4): 10651–10658, 2022。[DOI](https://doi.org/10.1109/LRA.2022.3193464)；[arXiv:2203.12071](https://arxiv.org/abs/2203.12071)；[Zotero](zotero://select/library/items/64JE36IC)。

**已阅读范围**：仅按清单定位到 Eqs (1)–(4)、Fig. 2、野外试验，未通读。

## 核心结论与研究设计

清单把这篇当作“用轨迹反推牵引”的轻量方法：在运动学模型里用 μ、ν 两个系数在线估计轮地牵引/滑移，μ、ν 接近 0 视为卡住/不可通行。

- 模型：Eqs (1)–(4)。
- 估计器：NMHE + EKF。[Fig. 2]
- 验证：野外试验。

## 核心证据与异常

| 问题 | 论文证据（页码 / 公式号 / 表号） | 解释与边界 |
| --- | --- | --- |
| 怎么估计牵引？ | Eqs (1)–(4)：运动学模型中的 μ、ν 两系数 | 两系数是运动学等效量，不是接触力学参数。 |
| 什么算“卡住”？ | μ、ν 接近 0 视为卡住/不可通行 | 阈值要按本机数据定，不能照抄。 |
| 能直接用于台阶接触吗？ | 清单明确指出：不建模法向力/台阶碰撞 | 首版台阶接触不适用，只能用于平地牵引与打滑。 |

**不能外推的地方**：首版台阶接触不适用（它不建模法向力/台阶碰撞）；只用于平地牵引/滑移。

- 把 μ、ν 接近 0 作为“卡住”的报警条件之一（阈值待标定）。
