## 核心结论与研究设计

清单把这篇定为“通过/不通过”与“最大可通过高度”的权威定义，决定仿真结果怎样和实机试验对齐。

- 测试床：§6.1.2.1（尺寸与地面要求见标准原文）。
- 门槛规格：§6.1.2.2 + Table 3，三种形状（圆柱 / 矩形 / 梯形）；具体几何、材质与安装要求见标准原文。
- 自动模式：§6.1.3.1，起始位置、计时与重复次数见标准原文。
- 手动模式：§6.1.3.2，起始距离、初始高度与通过判据见标准原文。
