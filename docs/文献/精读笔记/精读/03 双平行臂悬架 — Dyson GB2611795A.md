# 越障失败可能不是扭矩不够，而是后仰让下视传感器误判

**论文**：Lloyd Genn Stuart、Mohana Das Vinod、Azfar Saupi Sharir、Fazlinda Alias Nor（发明人），Dyson Technology Ltd，*A robotic vacuum cleaner*, GB2611795A, 2023（授权公告 GB2611795B, 2024）。[Google Patents](https://patents.google.com/patent/GB2611795A/en)；[Zotero](zotero://select/library/items/ETLJ8LXT)。无 DOI。

**已阅读范围**：本地 PDF 为扫描件、正文不可检索；仅按清单定位到摘要与权利要求 1–6、Figs 4–6、Figs 9–10，未通读。

## 核心结论与研究设计

清单把这篇定为少见的、给出真实扫地机悬架具体尺寸的公开专利：86 mm 轮径、A/B 枢轴 14.3/21.3 mm、B/A≈1.43–1.5、弹簧约 0.96 N/mm，并给出“越障后仰导致下视传感器误触发”的失效链。

- 结构：双平行臂，第一/第二臂分别铰接在减速箱与机身，靠后枢轴间距大于前枢轴间距抑制后仰。
- 失效链：单臂悬架越障时后仰 → 机身前缘离地距离变大 → 下视测距传感器超过阈值 → 控制器停机或倒车，放弃越障。[说明书背景段]
- 曲线：Figs 9–10 给 downforce–extension 与 downforce–moment，对比不同悬架配置。[Figs 9–10]

## 项目应用

- 在首版 P-0 的单臂悬架之外，增加一个“双平行臂”对照模型。
- 解释实机“越障时突然放弃”的可能原因：先查下视传感器阈值与机身俯仰，而不是只查扭矩。
- 给轮径/枢轴/弹簧一个真实量级（86 mm / 14.3–21.3 mm / 0.96 N/mm）。
