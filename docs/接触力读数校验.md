## 1. 结论（只陈述读数）

`mujoco.mj_contactForce` 返回接触帧下的法向 `res[0]`、切向 `res[1..2]`（N）和力矩 `res[3..5]`（N·m）。在平地静置、30° 斜面静置和密度翻倍三档工况、金字塔与椭圆两种摩擦锥共 6 次运行中：

- 法向力与理论值最大偏差 **0.000539%**（限值 1%）；
- 斜面切向力最大偏差 **0.000001%**（限值 2%）；
- 接触合力竖直分量最大偏差 **0.000468%**（限值 1%）；
- 平地两种摩擦锥的法向力差 **0.000000%**（0.5% 以内直接通过）；
- 密度翻倍后法向力比值 **2.000000000**（理论 2，偏差 0.000000%）。

坐标系、单位与正方向见第 5 节。签字状态：**机理级通过 / 定量待标定**（口径由仿真专家给出，本文件只交数据）。

## 2. 测了什么

脚本对以下三档工况各跑两种摩擦锥，均为静置后连续 100 步（0.05 s）取平均：

| 工况 | 场景 | 理论判据 |
| --- | --- | --- |
| `flat_sphere` | 半径 0.1 m、密度 1000 kg/m³ 的球自由落到平面并静置 | `Fn = m*g`（±1%），切向力为 0 |
| `incline_box` | 30° 斜面上边长 0.2 m、密度 1000 kg/m³ 的方块静置，滑动摩擦系数 1.0（≥0.6，且大于 tan30°） | `Fn = m*g*cos30°`（±1%）、`Ft = m*g*sin30°`（±2%）、接触合力竖直分量 `= m*g`（±1%） |
| `double_mass` | 球密度改为 2000 kg/m³，其余同 `flat_sphere` | `Fn` 翻倍（±1%） |

- 斜面用方块而不是球：无滚阻的球在斜面上必然滚动，方块可真正静置，同时用接触帧旋转检验法向/切向分解。
- 平地工况的两种锥没有切向需求，判据为：法向差 ≤0.5% 直接通过，0.5%~1% 通过但记录，>1% 判实现错误。
- 每个工况还检查：接触对 `geom1/geom2` 顺序、接触法向、采样窗口质心漂移、穿透、`d.warning.number`、NaN、力矩和锥型。

### 运行参数（脚本内固定）

| 项目 | 值 |
| --- | --- |
| 时间步 | 0.0005 s |
| 积分器 / 求解器 | Euler / Newton，200 次迭代，tolerance 1e-10 |
| 接触维数 | `condim=3`（法向 + 2 切向；无扭转/滚动摩擦） |
| 接触参数 | `solref="0.005 1"`，`solimp="0.999 0.9999 0.0001"` |
| 摩擦系数 | 滑动 1.0，扭/滚 0.01（`condim=3` 时不参与） |
| 球 / 方块质量 | 4.188790 kg / 8.000000 kg（由 `model.body_mass` 读出） |
| 球初始高度 / 方块初始间隙 | 0.4 m / 2 mm |

提高接触阻抗并减小时间步是为了压住斜面持续切向载荷下的软约束蠕滑（见第 7 节）。该设置只服务静置读数校验，不代表整机模型应使用的时间步或接触柔度。

## 5. 坐标系、单位与正方向（启动整机建模前确认）

1. **读数接口**：力只从 `mujoco.mj_contactForce(model, data, i, res)` 读取。`res[0]` 为法向力，`res[1..2]` 为切向力，单位 N；`res[3..5]` 为力矩，单位 N·m。不用 `efc_force` 行相加当力（金字塔锥 + `condim=3` 的约束行是棱边系数，已在旧脚本中证明其最大值 10.273 N 与球重 41.09 N 不一致）。
2. **接触帧**：`data.contact[i].frame` 是 3×3 行主序矩阵，三行依次为世界坐标下的法向和两个切向。返回值在接触帧内，世界分量按 `f_world = frame.T @ res[0:3]` 旋转；直接把三个分量当世界坐标是错的。斜面工况实测法向 `[0.5, 0, 0.866025]`，不旋转会得到错误的世界分量。
3. **单位与量纲**：力 N，力矩 N·m；重力 9.81 m/s²。平地球重 `m*g = 4.188790 × 9.81 = 41.092032 N`。
4. **正方向**：力由 `geom1` 指向 `geom2`，即**对第二个 geom 为正**。本校验把地面/斜面放在 `geom1`、被支撑物体放在 `geom2`，实测 `res[0] > 0` 且世界合力竖直向上（`+z`，抵消重力）。输出中每次都打印 `geom1/geom2` 名称；顺序反过来时符号也反过来测量。
5. **接触对**：`condim=3` 的点接触无扭转/滚动力矩，实测 `|res[3..5]| = 0`。

一句话结论：**读数在接触帧内、力的单位是 N、`res[0]` 沿法向且对 `geom2` 为正；世界分量必须用 `contact.frame` 的转置旋转，本校验的 `geom1/geom2` 顺序为地面/物体。**

## 6. 复现判据

脚本对每个工况输出 `PASS/FAIL`，总判定要求 6 次运行全部通过且锥间等效、质量翻倍比例通过。任一出现以下情况即判失败：

- 法向、切向或竖直分量超限；
- `geom1/geom2` 顺序与约定不符；
- 静置后仍有明显漂移（抽样窗口质心漂移 > 参考长度 0.1%）或未收敛；
- 穿透超过参考长度 5%；
- `warning.number` 非零、出现 NaN/Inf、`res[3..5]` 非零；
- `model.opt.cone` 与本次运行声称的锥型不一致。

## 7. 已知限制与边界

1. **只验证静置读数，不验证动态接触**：没有覆盖碰撞冲击、滑动摩擦、滚动/扭转摩擦（`condim=3` 不含后两者），也没有覆盖台阶棱边、网格或软体接触。
2. **MuJoCo 接触是软约束**：斜面上持续存在切向重力分量时，默认参数下会缓慢蠕滑（同一场景、默认 `solref=0.02`、`dt=2 ms` 时实测约 3.35e−3 m/s）。本校验用 `solref=0.005`、`solimp=0.999/0.9999`、`dt=0.5 ms` 把残余速度压到约 1e−5 m/s、抽样窗口漂移约 4e−4 mm；这不等于证明严格零滑移，长时间积分仍可能有累积漂移。
3. **接触几何有限**：只用平面—球（1 个接触）与平面—方块（4 个角点接触）两种组合，不能外推到多体、多点或复杂几何。方块四角接触的切向力分配依赖求解器，本次只核对合力。
4. **参数与整机模型无关**：球/方块质量、尺寸和接触刚度是为校验构造的，不是扫地机原型参数；不能把本页的力值当作整机载荷结论。
5. **平台与版本单一**：只在 Windows + MuJoCo 4.0.1 + NumPy 2.5.5 + Python 3.13.1 上执行；Mac 工作区未安装 MuJoCo，未做跨版本对照。
6. **符号约定的适用范围**：正方向按 `geom1→geom2` 记录；若后续模型把地面放在 `geom2`，同一行读数会变号，输出必须同时标出接触对名称。
7. **签字边界**：本文件只交付机理级读数校验数据（机理级通过 / 定量待标定）；接触参数标定、整机通过能力和实机对照不在本步范围。

## 8. 后续影响

- 整机模型与批运行入口应按本页约定用 `mj_contactForce` 读取接触力，导出时保留 `geom1/geom2` 名称、接触帧法向和世界分量，并记录 `condim`、锥型、时间步与求解器。
- 动态工况（越障冲击、切向滑移、多接触）需要另做读数校验；本页只能作为静置读数的地基。
