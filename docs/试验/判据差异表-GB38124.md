## 填表纪律

- 「GB/T 38124」栏只填**条文号**；原文关键句只记入本地私有摘录、**不入库**；未摘录前一律写 `待摘录（GB/T 38124-2019 §5.1.5）`，**不许凭印象填，不许用二手解读代替原文**。
- **来源已定 ≠ 原文已核**：`source_type: secondary`、`pending_verification: true` 两字段继续随行（P-1/P-2 表头）；取得正版后按变更记录处理。
- 「IEC 62849 §6.1.3」栏只作参考/锚定，一律写 `未知（正版未取得）`；P-1/P-2 已登记的二手条目按该文引用，不把二手条号升级成来源。
- 「本轮采用」栏写 `按 GB/T 38124（P-2.1）`、`按 P-2.1` 或 `按本方案（标【工程假设】）`，不留空。
- **不许默认等同**：GB/T 与 IEC 未取得部分不得写「同 GB/T」「同上」「按惯例」；也不得写与 `GB/T 38834.1` / `ISO 18646-1` 等同或符合（P-2.1）。
- 与标准冲突时以标准为准；验收限冻结后按变更流程走。
