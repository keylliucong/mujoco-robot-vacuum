# 平行轴换算留痕（惯量参考点换算）

- 版本：v1 · 2026-11-21 · 试验标定
- 用途：记录每次惯量参考点换算，供台账 `ref_point=body_CoM` 主行与 `ref_point=B_origin` 互校行对账。

## 1. 公式

`I_o = I_c + m(|r|²E − r rᵀ)`

- `I_o`：目标参考点 o 下的惯量张量；
- `I_c`：质心 c 下的惯量张量；
- `m`：刚体质量；
- `r`：从目标参考点 o 指向质心 c 的位移向量（B 系，mm；计算时换算为 m）；
- `E`：3×3 单位阵；`r rᵀ`：外积。
- 反向换算用 `I_c = I_o − m(|r|²E − r rᵀ)`，`r` 方向取反；两行必须能互相换算回去。

## 3. 纪律

- 主行取 `ref_point=body_CoM`（MuJoCo `inertial fullinertia` 即关于质心），同时出一行 `ref_point=B_origin` 的换算值供互校。
- 一行一次换算；`config_id`、`axes=B` 与 `ref_point` 同步记入 `docs/参数溯源.csv` 的 `ref`。
- 主行（`ref_point=body_CoM`）与互校行（`ref_point=B_origin`）必须追溯到**同一次测量**：同一 `src_path`、同一 `date`、同一批次编号。不得各记各的日期，否则互校退化成两个各自带误差的数摆在一起。
- 位移向量与质量必须与同批次的 `m`/`com` 行一致；不一致时先查台账。
- 换算对不上时不得改主行数值，单列偏差并上报。
