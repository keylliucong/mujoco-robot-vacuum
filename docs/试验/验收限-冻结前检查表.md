## 2. 两条不可签项

> 命中任一条即**不得签署**。这两条与上表的「可签」不同：它们破坏的是证据本身，事后补一份声明修不回来。

### 2.0 机械判定（评审不用问人）

| 项 | 看哪个文件 | 看哪一段 / 列 | 命中即不可签 | 怎么查 |
|---|---|---|---|---|
| 留出集封存指纹缺失 | `docs/试验/验收限冻结-2026-11-21.md` | 附件 A 段的 `路径` / `sha256` 两列 | 附件 A 段内**没有任何一行 `sha256` 是 64 位十六进制**，或签署提交里**没有附件 A 段** | 用 §4 命令 1 抽取附件 A 后 `grep -E '[0-9a-f]{64}'`，无输出即命中 |
| 冻结晚于首次读取 | 同上 | 附件 B 段的 `日期` 列；正文 `frozen_at` | 附件 B **有任一非空数据行**，且该行 `日期` **早于** `frozen_at` | 下方 §2.2 命令取附件 B 首行日期，与 `grep 'frozen_at=' <file>` 比较 |

> 两条都能只看**一个文件、一列**就判完；不需要打开留出集原始数据。

### 2.1 留出集封存指纹（附件 A）缺失

**最小判定**：附件 A 段内没有 64 位十六进制的 `sha256` 值，或签署提交里没有附件 A 段 → **不可签**。

完整封存还须满足下列 6 条（缺任一条同样不可签）：

1. 附件 A「提交号」指向**留出集文件被冻结的那个已存在提交**，不是签署提交自身（文件无法写入自己的 sha），且该提交是签署提交的祖先。
2. 被冻结文件清单至少 1 行，每行 `路径 + sha256` 均已填，无 `TODO`。
3. 计总指纹算法写明：排序规则、是否含路径、编码。
4. 文件数与 case 数**由清单数出来**，与清单行数一致，不另报一个数。
5. 见证句在文件里，含「不构成认可」+ 见证人 / 日期 / 提交号；未取得见证人则明确写「无见证人」。
6. 附件 A 与附件 B 在**同一提交**——分开提交，中间就是无证据窗口。

**不可签的理由**：没有指纹，就无法证明签署时留出集未被读取或改动；「已经封存了」这句话本身不可复核。`frozen_at` 写得再早也不能替代指纹。

### 2.2 冻结晚于首次读取

**最小判定**：附件 B 有任一非空数据行，且该行 `日期` **早于** `frozen_at` → **不可签**（先读后冻）。

签署提交上还须同时满足下列 3 条（第 1 条不成立直接判不可签）：

1. 在签署提交 `<sig>` 上，附件 B 表体为 **0 行**（只有表头与分隔行）。
2. `frozen_at` 不晚于 `<sig>` 的提交日期。
3. 附件 B 第一条数据行出现在提交 `<read>`，且 `<sig>` 是 `<read>` 的祖先（或 `<sig> = <read>`）；`<read>` 日期不早于 `frozen_at`。签署前任何报告若引用了留出集结果，同样判「先读后冻」。

**取数命令**（在仓库根执行；表体数据行 = 计数 − 1，表头占 1 行）：

```sh
for c in $(git rev-list --reverse HEAD -- 'docs/试验/验收限冻结-2026-11-21.md'); do
  n=$(git show "$c:docs/试验/验收限冻结-2026-11-21.md" 2>/dev/null \
      | awk '/^## 附件 B/{f=1;next} /^## /{f=0} f && /^\|/ && $0 !~ /^\|[[:space:]]*-/ {k++} END{print k+0}')
  printf '%s  attachment-B rows=%s\n' "$(git show -s --format='%h %ad' --date=short "$c")" "$((n-1))"
done
```

**不可签的理由**：留出集一旦在签署前被读过，签署就不再是「先定判据、后看结果」；事后把日期改早、或声称「只看了一眼」都无法恢复留出集的资格。

## 3. 本表自身的结论边界

- 本表**只给判定方法**，不给「当前已冻结 / 未冻结」以外的结论。
- 按 §2.1 的最小判定，当前附件 A 段内没有 64 位 `sha256`（仍是 `TODO`），故当前状态为**不可签**；§2.2 在签署动作发生前无法用「未来未发生」来自证，只能在签署提交上按 §2.2 逐条核对。
- 验收限正文的冻结状态仍以 `docs/试验/验收限冻结-2026-11-21.md` 的 `frozen_at` 为准；本表不修改该字段。

## 4. 签署前机械检查（照抄即可）

```sh
F='docs/试验/验收限冻结-2026-11-21.md'

# 1) 附件 A 是否有 sha256 行（无输出 = 不可签）
awk '/^## 附件 A/{f=1} /^## 附件 B/{f=0} f' "$F" | grep -E '[0-9a-f]{64}'

# 2) 附件 B 表体数据行数（必须为 0）与首行日期
awk '/^## 附件 B/{f=1;next} /^## /{f=0} f && /^\|/ && $0 !~ /^\|[[:space:]]*-/ {n++; if(n==2) print "first_row:", $0} END{print "data_rows:", n-1}' "$F"
grep -n 'frozen_at=' "$F" | head -1

# 3) 禁用词（报告文件，不含本检查表）
grep -F -f docs/试验/禁用词-评审清单.txt <报告文件>
```

> 第 1 条无输出 → 附件 A 缺指纹，不可签；第 2 条 `data_rows` 非 0 且首行日期早于 `frozen_at` → 判「先读后冻」。
