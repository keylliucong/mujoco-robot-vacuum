# 数据集划分-留出集 · 说明

配套：`docs/试验/数据集划分-留出集.csv`

> 按 heading 分列时生效值靠 `run.json.config{path,sha256}` 还原（`summary.csv` 列冻结、无 heading 列）。

- `group` 只决定「怎么分列」，不决定「等不等级」。本轮斜向组属留出集，**留出集结果不派 param 等级**；等级只来自拟合集的标定报告。
- `group` 只由 `|heading_deg|` 推出：`0 → 正对`，`15/30 → 斜向`。报告只读本 CSV，不许手写分组。
- CSV 与运行记录的 `heading_deg` 按 `case_id` 一致性核对，对不上就停、不手工改。
- **`cfg_sha256` 必须填当次运行实际使用的配置哈希，不是最后一次提交的哈希**。配置改过而没重跑时两者不一致，那串 sha 会变成"看起来有溯源"的假象。
- `cfg_path` 填仓库内相对路径，`cfg_sha256` 填该文件当次哈希。
- `cases/*.json` 必须进版本库，否则历史报告无法按 heading 复现。
