# 开环直线偏差 A 方案（地面标线法）记录表

- 依据：#78《开环直线偏差：标准条款与试验方法研究报告》§5A、§5.0
- 版本：空白表 v1 · 2026-11-27
- 适用：差速两轮（+ 从动轮/万向轮）扫地机器人，开环等占空比直行；不用于闭环导航或 IMU 纠偏
- 声明：本表只记录 #78 §5A 的试验，不改方法与判据；**本表不构成标准符合性声称**。

> 用法：每组试验填一次表头；每次运行占一行，正向、反向各不少于 5 行。无效运行也保留，在「有效/无效及原因」写明原因，不计入 n。
>
> 符号：机器人前进方向看，向左偏为正（§5A 数据处理）。y 单位 mm，D 单位 m。

## 4. 换算与公式（照抄 §5.0）

- 曲率：`κ = 2y/D²`（y、D 同单位；y 用 mm、D 用 m 时，`κ = 2y/(1000·D²)` rad/m）。
- mm 拟合：`κ = c/500`（rad/m）。
- 角度换算：`κ[°/m] = 57.2958 · κ[rad/m]`。
- 平均横向偏移率：`y/D`（mm/m）；`D = 10 m` 时，`1 mm/m = 0.01146 °/m`。
- 等效曲率半径：`R = 1/κ`（m）。
- `y/D` 是平均弦斜率，不是端点切向角；端点切向角 `ψ_end = κD`（§5.0）。
