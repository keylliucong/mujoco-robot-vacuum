# 报告排版约定

排版能制造文件里不存在的比较；文件层干净了而排版层还在比较，等于没修。

## 排版禁令（都是"文件里没有、排版造出来"的比较）

1. **不许共享可比纵轴**：小 `n` 组单独成图；散点图纵轴用**类别轴**（`cleared` / `blocked` / `invalid`），不出现数值纵轴。
2. **不许只报一个等级**：报告表与**图注**都必须写出来源字段名——`参数等级（label）` 与 `结论等级（conclusion_level）`。只写"等级"两个字，读者还得回来问这是哪个。
3. **不许"百分比"不带 n**：所有比率写成 `绝对数/总数 (百分比)`，`n < 10` 不给置信区间。

## 两条要求

4. 图注必带：`n=`、分组（正对/斜向）、`heading_deg` 符号、`v_impact` 与 A1–A4 是否满足。
5. 双列等级与图注规则对大 `n` 组同样适用（比率曲线只在同组内、同 `n`、`n ≥ 10` 时用）。
