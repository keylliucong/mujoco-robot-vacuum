# 报告排版约定

排版能制造文件里不存在的比较；文件层干净了而排版层还在比较，等于没修。

> `cleared` / `blocked` / `invalid` 是契约 §3.1 末段的**派生标签**，须由入库脚本生成；`invalid` 不得并入 `blocked`。报告引机器结论时，`status` / `passed` / `failure_primary` / `failure_flags` 原值照抄，不另造同义列。

## 排版禁令（都是"文件里没有、排版造出来"的比较）

1. **不许共享可比纵轴**：小 `n` 组单独成图；散点图纵轴用**类别轴**（`cleared` / `blocked` / `invalid`），不出现数值纵轴。
2. **不许只报一个等级**：报告表与**图注**都必须写出来源字段名——`参数等级（label）` 与 `结论等级（conclusion_level）`。只写"等级"两个字，读者还得回来问这是哪个。
3. **不许出现百分比/比率**：所有结果写计数，如「4 例中 3 例 `cleared`」，不写「75%」。`n < 10` 不给置信区间。

## 两条要求

4. 图注必带：`n=`、分组（正对/斜向）、`heading_deg` 符号、`v_impact` 与 A1–A4 是否满足。
5. 双列等级与图注规则对大 `n` 组同样适用；本轮不出现比率曲线与百分比（含大 `n` 组）。

本轮不出现任何比率曲线与百分比（含大 `n` 组）：比率是估计量、散点是观测；`n=20` 的二项 95% 区间约 ±22%，画成曲线会被当趋势读。

## 百分比机械检查

1. `grep -nE '[0-9.]+%' <报告>` 列出所有百分比行，人工过一遍；
2. `grep -nE '[0-9.]+%' <报告> | grep -vE '[0-9]+/[0-9]+ ?\([0-9.]+%\)'` —— **命中即拦**（不符合 `n/N (x%)` 形式的百分比）。

第 2 条是"允许形式的白名单检查"，不是禁用 `%` 本身。
