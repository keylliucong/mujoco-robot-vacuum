# 试验记录表模板（机体系 B，v2）

- 版本：v2 · 2026-11-21
- 责任人：试验标定（数据与标定结论签字）；物理合理性签字在仿真专家
- 依据：G2 接口契约 v1.2（机体系 B、第 6 标签【图纸推算】）、架构师 R-UNC-1 裁定、仿真专家负载三档口径
- 本模板只管"怎么记、怎么算、怎么判"；验收判据本身不在本文件，见 `docs/试验/验收限冻结-<日期>.md`

> A/B 归类原则：能按真实过程采样 → A 类；采不到只能评估 → B 类；「是否系统项」不作归类依据。

> `makerspet/oomwoo`（开源 DIY 扫地机器人）是**对标基准**，用于建立模型与做敏感性，**不代表本机型的机构方案**。报告中「按基准机型」与「按本机型」必须分开表述，不得合并。

## 0. 使用前提

1. 一个测点一行；同一参数不同 `load_state`、不同 `heading_deg`、不同日期、不同装夹各占一行。
2. 不确定度按 R-UNC-1 计算，**旧的 `T = 3·√(s_r²+s_f²)` 已降级为诊断列，不参与任何判定**。
3. 受限内容（原始测量数据、含厂商标识的尺寸表、CAD 实体）不入库；仓库只留记录表、数据字典与可共享摘要，原始件写路径。
4. 标定用 sheet 与验证用 sheet 分文件，不许混在同一张表里（拟合集/留出集物理分离）。

## 1. 每行字段

> 收货/记录表头：`makerspet/oomwoo` 是对标基准，不代表本机型；基准机型参数一律【公开参考】，不得顶替本机实测列。

| 列 | 含义 | 取值要求 |
|---|---|---|
| `field` | 参数名 | 用 `docs/试验/数据字典.md` 的字段名，不自造 |
| `value` | 测量值 | 按量具分辨力给位数，不多给 |
| `unit` | 单位 | mm / kg / kg·mm² / N/mm / N·s/mm / N·m / rad/s / A / V / — |
| `label` | 数据标签 | 本机实测 / 公开参考 / 工程假设 / 缺失 / 待标定（第 6 档【图纸推算】按契约条件使用） |
| `method` | 方法与仪器编号 | 量具＋编号＋证书编号，例：`卡尺#C-03/证书XXX` |
| `n` | 重复次数 | 用于算 s 的原始次数，不是"测了几次就报几次" |
| `u_A` | A 类标准不确定度 | `√(s_r² + s_f² + s_day²)` |
| `u_B` | B 类标准不确定度 | 由 `docs/不确定度预算.csv` 该参数各分量方和根，**不许空** |

| `diag_3sigma_A` | 诊断列 | `3·√(s_r²+s_f²)`，**只诊断，不判定** |
| `load_state` | 负载状态 | `unloaded` / `equiv_ballast` / `full_witness` |
| `heading_deg` | 接近方向角 | `±15 / ±30 / 0`，带符号，正角 = 左轮先触；与 B 系（+y 向左）一致；与契约 `scenario.heading_deg` 同名同义，记录该 case 的运行实际值 |

| `date` | 测量日期 | YYYY-MM-DD，跨日复测各一行 |
| `env` | 环境 | 温度 °C / 相对湿度 % / 气压 kPa / 照度 lx（标定环境照 IEC 62849:2025 记） |
| `v_meas` | 实测接近速度 | 触槛瞬间速度 `v_impact`（m/s），逐批填；缺值或非同源即该批不可用 |
| `soc` | 电池状态 | 电压 V 与 SoC %，固定口径见填写须知 |
| `note` | 备注 | 修正项、未修正项、偏离与理由；不得留空 |

> 任何参数行 `ref` 都必须带 `machine=own` 或 `machine=oomwoo`；缺该键的行视为不完整，不得进入报告。

- 无悬挂机型：`susp_*` 一组**留空并标 `missing=true`**，**不得填 0**。填 0 会被读成"行程是 0"，而 `5%·travel = 0` 会让 `A2` 永远失败。
- **CSV 空 ≠ 0**：空 = 未测/不适用（配合 `missing` 标记）；`0` 只在实测确为 0 时出现。
>
> 若某批扫描用的是基准机型（`machine=oomwoo`）的几何/质量属性，而结论写给自己机型，**该批数据无效**，且不得计入任何组。跨机型单独记 `excluded: cross_machine`，不并入 `invalid`、也不并入 `blocked`。

## 2. 计算与判定（R-UNC-1）

> **先固定参考点，再谈容差。** 参考点没写死之前，容差数字相同也是假的一致。

> **参数行等级**（台账、`run.json.params`）：只看 `label`，回答"这个数从哪来"。
> **结论等级**（如通过高度这类派生结论）：看「参数标签 **且** 容差刻度」，回答"这句话能说到多远"。
> 细则：参数全【本机实测】**且**比对该用的 `verified_tol` 齐备 → 结论可 `quantitative`；有 `pending` 分量 → **结论**封顶 `mechanism`；有 `assumed` 分量 → **结论**封顶 `sensitivity`。**参数等级不受影响。**

- 惯量对角容差本轮按 `5–10%（有值即可；3% 另议）` 落表；未裁定前不据此出判定。
- `3% 的取得路径见复核意见（转轴摆过质心，d ≤5 mm），不等同于收紧 com；契约口径待更新。`

- `u_A = √(s_r² + s_f² + s_day²)`，三项缺一不可：
  - `s_r` 重复性：同人、同装夹、同仪器、≤30 min 内连续重复的样本标准差（贝塞尔，n−1）；
  - `s_f` 装夹重复性：≥3 组重新装夹 × 每组 n 次，合并标准差；
  - `s_day` 跨日/批：≥3 个不同日/批、**同一参考件**复测的合并标准差。跨日漂移是 `u_A` 的一项，不是备注。
- `u_c = √(u_A² + u_B²)`；`k` 默认 2，ν_eff<10 用 t(0.975, ν_eff)，Welch–Satterthwaite 合并。
- `verified_tol = k·u_c`。
- **判定限 = 规格限 ∓ verified_tol**：
  - 双侧：`[LSL + verified_tol, USL − verified_tol]`；
  - 单侧（通过高度）：`实测 ≤ USL − verified_tol` 判通过。
- 比对容差（实测 vs 仿真）：`u_c,cmp = √(u_meas² + u_sim²)`；`u_sim` 至少含时间步长、接触参数、几何简化三项的灵敏度散布，由仿真专家提供。缺任一项，该行不出 `verified_tol`，只出 `u_meas` 与偏差，标「比对不判定」。
- 系统项**先修正后合成**；同一分量不得同时进 A 与 B。重复计入按「违反即失败」处理。
- `u_B` 不许空；判为可忽略也要量化（例：`u_B < 0.1·u_A`）并写不可采样的理由。空 = 未评估 = 该行无效。
- `u_B` 含【缺失】或【待标定】分量时，该参数结论等级不得高于 `mechanism`。
- 超差不直接判死：同一装夹复测一次、跨日复测一次，两次仍在容差外才记 `out_of_tol`，并保留三次原始数据。
- 可逐参数翻案：仪器校准证书经核 `< 0.1·u_A` 且不可采样项确为空，该参数可单独降为纯 A 类 k=3，行内标 `k=3 (per-param ADR)`，写进 `docs/参数溯源.csv`。**不设全局例外，绝不设全局 k=3。**

## 3. 坐标系与符号

- **B = world = chassis 局部系**：+x 前进、+y 向左、+z 向上，右手系；原点＝左右驱动轮轴心连线中点在地面的投影（z=0 在地面）。
- 车轮角速度 `omega_wheel`、轮端扭矩 `torque_wheel`：取 B 系绕 +y 轴分量后**取负**，前进/驱动为正。取值已取反，填表时不再二次判断。
- 悬挂压缩为正；`s_zero` 零点＝空载标准状态（标准电池、无尘盒水箱、轮胎冷态）静置于水平硬质松木板上的静平衡位；满载报增量。
- 电机端与轮端分列，`i_gear` 单列。
- 轮心高度 `hub_z` 空载、满载两个值分列——它决定 B 系原点 z，且受轮胎压缩影响。

> 实测质心与模型 CoM 均按 §1.1 的 B 系原点换算后比较，±1 mm 在该参考点下成立。

1. **±1 mm 只对 CoM（长度量）。** 惯量用试验方案既定容差（对角 `5–10%（有值即可；3% 另议）`；惯量积本轮按对称设 0 结案），两者不可互换；
2. **平行轴换算会放大误差**（r² 项），换算过程要留痕，否则 1 mm 的参考点偏差在惯量上不再可忽略、还查不出元凶。

- `derived_from` 引用的 `m` / `com` 行必须与本源行**同属一个（`payload_state`, `config_id`）分组**，由脚本查；"同 `src_path` + 同 `date`"不够，两样都可能相同而批次不同。
- **同源换参考点 = 复算**（`role=derived`）：只能验换算算术有没有写错。
- **互校 = 独立来源**（`role=check`）：必须有自己独立的 `original_file`。
- 原「主行 `body_CoM` + `B_origin` 换算行互校」**降级为 `role=derived` 复算**；真正的 check 只能靠独立方法（例：三线摆与复摆测同一轴，或整机与分部叠加两种路径），在没有第二种方法前该参数**没有 check**，写成"无独立校核"而不是"已互校"。

## 4. 负载状态三档

- `unloaded`（主口径）：尘盒空、水箱空。G4 拟合集全用此档。
- `equiv_ballast`（辅口径）：刚性等效配重，设计点 0.50 kg，区间 0.35–0.65 kg，0.05 kg 步进。等效性由三条几何不变量判：① 地面接触包络不变；② 跨越方向正面轮廓不变（前缘 x、对门槛棱边的接触点与时序不变）；③ 不引入新接触面。顶部刚性外挂可接受；`Δz_cg`（外挂实测质心高 − 真实满载推算质心高）仅作记录项，不再赋予「保守」含义。
- `full_witness`（旁证）：真实尘水，单次，仅最终验收测一次，不进拟合。
- **满载静态 = 水箱满水且排净空气、尘盒装满并压实、均封盖。**
- 物理依据：满水箱测不出质心，原因不是"水是液体"，而是**箱里有空气**；有空气才有自由液面。装满、排净气泡、封盖后容器内没有自由液面，水被完全约束，力学上就是刚体，倾斜/多支点法测出来的是机器属性。
- **禁用两条**：不得用"水箱几何质心"（壳体不装水，会系统性偏）；不得自行引入 80% 水位（等于悄悄换定义）。
- 刚性配重块是它的**等价物**（用于反复试验），不是替代品；取哪套由工装说，不由口径说。
- 三档 σ 各自成池，**不并池**；负载是实验因子（enumerate 的 level），不是随机误差源。
- 每档每次试验记录该次配重总成的实测质量与质心作为运行元数据；不同叠块组合各记一套。

> 同一载荷状态的 `m / com / inertia` 必须成套有台账行；值可以是【缺失】，但必须成行——「没这一行」不是表达缺失的方式。载荷附加惯量独立成行，不得借用空载或整机惯量行顶替。缺任一行，该载荷状态不得出定量结论。成套性分组键为（`payload_state`, `config_id`）；`sealed_full_water` 与 `equiv_ballast` 各占 `param_id`，不得共用。惯量行 `ref` 必须声明 `ref_point` 与 `axes=B`。

> 同一载荷状态的 `m / com / inertia` 必须成套有台账行；值可以是【缺失】，但必须成行——「没这一行」不是表达缺失的方式。载荷附加惯量独立成行，不得借用空载或整机惯量行顶替。缺任一行，该载荷状态不得出定量结论。成套性分组键为（`payload_state`, `config_id`）；`sealed_full_water` 与 `equiv_ballast` 各占 `param_id`，不得共用。惯量行 `ref` 必须声明 `ref_point` 与 `axes=B`。

> **惯量积按对称设 0 的理由**：机器左右对称（关于 xz 平面）时 `Ixy = Iyz ≈ 0`，张量只剩 `Ixz` 一个非对角项。对纯俯仰（ω 只有 y 分量）：`H = I·ω` 的 x 分量 `= Ixy·ω`，**`Ixz` 不出现**；`ω × H` 的剩余项由 `Ixy`、`Iyz` 决定，按对称设 ≈0，故陀螺项为零。因此正对门槛的准静态批次里 `Ixz` 影响是**精确的零**，不是"很小"。

- 本轮不做单轮先上、斜向接近、门槛左右不等高，故整行直接结案、不扫；`I_xy/Izz` 由报告口径给出（派生量，非独立测量），台账不占行；斜向批次标「斜向待裁」。

> 本结案只对**正对门槛 + 纯俯仰 + 左右对称**成立。斜向 15°/30° 属单轮先上工况，ω 有 x/z 分量，`Ixz`/`Ixy` 均进方程，陀螺项非零——该类批次若出现在留出集，结果旁注明「`Ixz` 按对称设 0，未经验证」；该注明只说明该组前提，等级由组别决定。

- `travel` 是批可用性的前置量（`A2` 阈值 `min(0.5 mm, 5%·travel)` 依赖它），**D1 必须测出**；未测出 `travel` 前该批 `A2` 记不可判、整批按不可用处理，**不得事后补测推定**——事后补的 `travel` 等于用后验知识判前验批次，该批数据的有效性论证就断了。

### 5.1 轮胎压缩的算法规矩

- 空载、满载两态的轮胎压缩**各自独立算 `s_r`**，两态之差**不得并进 `s_r`**——否则 `s_r` 虚大、判定门虚宽，等于反向犯错。
- 两态之差是载荷因子的水平差，按因子报告，不进任何 σ 池。
- 只有「实际载荷 ≠ 标称载荷」这一残差进 `u_B`（见 `docs/不确定度预算.csv` 对应行）。

### 5.2 满载静态与配重

> 满载静态 = 水箱满水且排净空气、尘盒装满并压实、均封盖。

- 物理依据：满水箱测不出质心，原因不是"水是液体"，而是**箱里有空气**；有空气才有自由液面。装满、排净气泡、封盖后容器内没有自由液面，水被完全约束，力学上就是刚体，倾斜/多支点法测出来的是机器属性。
- **禁用两条**：不得用"水箱几何质心"（壳体不装水，会系统性偏）；不得自行引入 80% 水位（等于悄悄换定义）。
- 刚性配重块是它的**等价物**（用于反复试验），不是替代品；取哪套由工装说，不由口径说。

**现场执行清单**

1. 尘盒装满试验尘、压实、封盖，称 `m_dust`；
2. 水箱装满水、排气、封盖，**倒置 10 min 验漏**——密封不过关则倾斜法作废；
3. 装回整机称 `m_full`（校核 ≈ `m_dry + m_dust + m_water`）；
4. 倾斜/多支点测满载 `(x_cg, z_cg)`，重复 5 次给 3σ；
5. 算配重目标：`m_b = m_full − m_dry`；`x_b = (m_full·x_full − m_dry·x_dry)/m_b`（z 同理）；
6. 装配重后复测整机质心落点，±1 mm 内合格（仅 CoM，按 §3 参考点口径），锁死叠块组合并记录。

- x/z 三处必须同一坐标系（机体系 B）、同一载荷状态，不得混空载与满载读数。
- **记录排气方法与静置时间**作元数据——留一个气泡就等于没做。

**工装：一套，共底板**

- 标定阶段：用产品自己的水箱/尘盒，装满排封，测一次，得实测 `m_full` 与 `(x_cg, z_cg)`。
- 反复试验：刚性配重总成复现那两个数。做成**共底板**——一块销定位底板，上面能换装「金属块」或「密封水容器」，共用同一组定位销，**不备两套**。

**报告限定**

> 配重只复现 m 与质心，不复制惯量——真实尘水是摊开的，配重块是集中的。因此配重法只对「准静态通过高度」负责，不对「冲击峰值力、接触力时程、翻越瞬态」负责。

- 真实有气的水在爬槛抬头时向**后下方**流，质心降低后移，等于更好爬；所以任何刚性化处理相对"有气真水"都是**保守**方向。
- **用于 G6 图注**：

  > 刚性配重复现满载质量与质心（落点 ±1 mm）：准静态通过高度为有效下界，CG 残留为 ±1 mm 双向偏差；因配重集中、真实尘水摊开，转动惯量未复现，故冲击峰值力、接触力时程与翻越瞬态不适用，不构成界。

- 图注只写「±1 mm 双向偏差」，不写通过高度的具体毫米数——系数取决于 `∂h_pass/∂z_cg`，要 G5 敏感性才算。
- G5 出数后，若量级确为 1:1 且 ≤2 mm，才允许加一句「该项对通过高度影响 ≤2 mm 量级」。在此之前有人问统一答：「量级同阶，系数待 G5」。

**准静态两层判据（判据误差预算取 1%）**

**第一层 整车平移**：判据用 `v_impact`（触槛瞬间速度），阈值按 Δh 查表：

| Δh | v 上限 |
|---|---|
| 20 mm | 0.063 m/s |
| 30 mm | 0.077 m/s |
| 40 mm | 0.089 m/s |
| 50 mm | 0.099 m/s |
| 60 mm | 0.109 m/s |

1. **1% 是判据误差预算的选择，不是物理常数**：条文写"本判据取 1%"；取 0.5% 则速度上限降 1/√2，取 2% 则升 1.41 倍。改这个数等于改适用范围，须走变更记录。
2. **必须记录触槛瞬间实测速度 `v_impact`（记录表列 `v_meas`），不能只勾"满足判据"**。`v_impact` 超表值的批次是动量辅助试验，**不能进准静态拟合集**，单列并标原因；**没有 `v_impact` 记录的批次一律按不可用处理**。逐批填，写进记录表。
3. **适用范围**：主口径准静态结论只对 `v ≤ 0.077 m/s` 成立，**不等于产品实际使用条件下的越障能力**（正常清扫 0.2–0.3 m/s 时动量占比 6%–15%，正好一阶）。这句同时进验收限「适用范围」段与 G6 图面（图横轴旁标 `v ≤ 0.077 m/s`），不能只写技术附录。
4. **同源同帧**：`v_impact` 与接触触发信号必须**同一设备、同一时钟**（≥100 fps 视频同帧可见触发指示，或激光测速与接触触发共用同一采集卡）；不同源的批次 `v_impact` 记 `invalid`，该批按不可用处理，不得事后对齐估算。

**第二层 悬挂**（逐批判，`note` 必填项）：

> 过槛期间悬挂压缩量相对**同一批次静态平衡位**的最大偏差 `< min(0.5 mm, 5%·travel)`（取严）；接近段加速度 `≤0.05 m/s²`（速度恒定）。

- 阈值写成 `min(0.5 mm, 5%·travel)`，`travel` 实测后代入；未测出 `travel` 的批次该项不可判 → 该批不可用。
- 悬挂压缩量记录用 ≥1 kHz 位移采集（激光位移或拉线式），与 `v_impact`、接触信号同一次录制的同一时间基准。
- **仅速度满足、悬挂被判激励的批次，即使 `v_impact` 在表内，也按不可用处理**，单列并注原因。
- 对应验收限 §5 方法有效性条件 A1–A4（A1 整车、A2 悬挂、A3 加速度、A4 电流代理）。
- 批可用性检查：以 `z_cg` 为横轴的结论若未标「扫描范围内」，视为不可用。

**扭矩无阶跃（电流代理，阈值【工程假设】）**

- 采样 ≥1 kHz，先做 20 ms 滑动平均得 `I_f`（覆盖 PWM 与换向纹波）。
- 稳态段 = 触槛前 `0.5 s`。
- 判据①波动：`(I_f,max − I_f,min)/I_f,mean ≤ 5%`。
- 判据②无冲击：稳态段内任意相邻两个 20 ms 窗口的均值之差 `≤ 10%·I_f,mean`。
- 两条都满足才记「无扭矩阶跃（电流代理）」。
- 记录 `env` 里加电机温度或至少环境温度，`soc` 必填——**电流→扭矩的代理关系未标定**，只在转速与温度稳定时近似成立。
- 记录表必须写明原文：**「电流是扭矩的代理量、代理关系未标定；本列不得用于任何定量扭矩结论，也不得作为本轮扭矩实测数据引用。」**
- 阈值标【工程假设】，待代理关系标定后修正，走变更记录。

> 小 `n` 组（`n < 10`，含斜向组 `n=4`）**不画比率曲线**，改**逐 case 散点、按组分面**（横轴 Δh，点形表 `outcome`：`cleared` / `blocked` / `invalid`）。比率曲线只在同组内、同 `n`、`n ≥ 10` 时使用；不同 `n` 的比率不同图比较。
> 分面规则、点形与 `outcome` 的对应关系**由仿真专家定**，本文件先按上述默认写法，它定完按它改。

**命名升档条件**（三条全满足才改名）

「配重下界」→「满载静态下界」要求：

1. `m_full` 与 `(x_cg, z_cg)` 是密封满水状态下**实测**（不是 CAD 推算、不是假设标签）；
2. 配重总成的实测质量与质心能把整机质心落到目标点 **±1 mm**（仅 CoM，按 §3 参考点口径；复称验证）；
3. 记录表里有排气方法、密封测试结果与环境条件。

### 5.3 载荷附加惯量的可测性（proposed，待裁定）

- **本轮处置**：`sealed_full_water` / `equiv_ballast` / `full_witness` 的 `I_att_*` 一律 `label=【缺失】`，`note` 写原因：**配重法复现不了、本轮不做实测（惯量不进准静态判据，见 §5.3）**。

- **空载惯量照旧必测**（P0 四项之一，不涉及差分，直接测 3% 无放大问题），不受本条影响。
- 本轮目标仍写 **5–10%、有值即可**；工装按过质心设计，若实测 `u_c` 支撑 3% 就按实测报，不虚标也不压制。

> 惯量不进准静态判据：通过条件式里只有 m·g、几何、摩擦、驱动扭矩，没有 I。它不是"影响小"，是"条件方程里没有这一项"。惯量只从两条路进结果——瞬态（冲击、俯仰振荡、打滑收敛）与动量型越障（½Iω² 为一阶量）——这两条都已排除在本轮结论范围外。

- **报告纪律**：G5 扫描结果出来之前，任何"惯量是二阶 / 无关"的说法都只是分析，不是数，报告里不许提前写。
- **G5 证据路线（扫描纪律）**：扫描区间 `0 → I_att,max`（采样点 `0 / 0.25× / 1× / 2× / I_att,max`）；上界取 `min(物理上界, 3×当前假设值)`，并写明取哪个与理由；`I_att,max = m_att · k_max²`，`k_max` 取实测最大半尺寸；若 `I_att,max` 低于几何推算值，退回重推、不调上界；`0` 是物理真下界（无附加惯量），必须包含。报告只许写「在扫描区间内未翻转」，不许写「不敏感」「可忽略」。
- **可测性（下一轮）**：密封满水（`sealed_full_water`）力学上是刚体，可用同一套三线摆/复摆测 `I_full`，`I_att = I_full − I_dry`；`equiv_ballast` 配置同理可测（`I_att = I_ballast − I_dry`）；`full_witness`（有气真水）因自由液面使惯量与姿态相关，不可测。
- **技术前提**：差必须在同一参考点与同一坐标系下做（`I_full` 关于满载质心、`I_dry` 关于空载质心，需按平行轴定理转到共同参考点后再相减），否则差值没有物理意义。
- **方法注意**：无自由液面时水随容器刚体转动，但粘性低、快速摆动可能出现内部二次流；惯量测量取低频小振幅（≤5°、周期 >1 s），并记「有效惯量」与频率依赖。
- **两套配置各占 `param_id`**：`sealed_full_water` 与 `equiv_ballast` 不共用；`config_id` 记入台账 `ref`。键形按 `<machine>.<payload>.<param>`（`payload ∈ {dry, ballast, full}`），载荷附加惯量六分量各占一键（`I_att_xx` … `I_att_yz`），**不设张量容器单键**。
- **TODO(试验标定)**：`sealed_full_water` 与 `full_witness` 都落到 `payload=full`；两者是共用 `own.full.*`（用 `config_id` 区分）还是分列，待台账 owner 定。未定前分别记录，不得合并成一行。

### 5.4 摩擦数据交付：两行，不是一行

> 交付给仿真侧的摩擦数据**必须分两行**：`mu_s`（轮–层压板）与 `mu_step`（轮–铝门槛），各带独立 `verified_tol`。**不得合并成一个 `mu`**。

理由同契约 `S24` 的禁止项：pair 摩擦下沉到 geom 会把"轮–地"与"轮–台阶"静默合成一个值，二维扫描降成一维、且不报错。仿真侧要按 5 分量写 `<pair friction>`，试验侧就要按两行给数——**两边必须一一对应，否则下游只能合并回去**。

| 行 | 接触对 | `param_id` | 记录表 `field` | 本轮标签 | 目标 `verified_tol` |
|---|---|---|---|---|---|
| 1 | 轮–层压板 | `own.mu_s` | `mu_s` | 【待标定】 | 5%（相对；须先过「`value` 量级 < 10×`verified_tol` 时禁用相对口径」这一条） |
| 2 | 轮–铝门槛 | `own.mu_step` | `mu_step` | 【待标定】 | 5%（相对，同上） |

- 两行**各占一个 `param_id`**，不可互为别名；不建 `mu`、`mu_ground` 之类的合并键。
- 两行各自算 `u_A` / `u_B` / `u_c` / `verified_tol`：一行 `pending` 不得让另一行跟着为空。本轮两行均【待标定】，`verified_tol` **为空**，不得填 0 占位（`CAL-023`）。
- 交付时每行必须带：`value`、`unit`、`verified_tol`、`verified_by` / `verified_delta`、`ref`（含 `source=` / `retrieved=` / `rev=`，能 pin 就 pin）。
- 量的定义写死在行里：`mu_s` = 轮–层压板；`mu_step` = 轮–铝门槛。门槛材质、表面状态变化时该行重测，不沿用旧值、不换名。
- `mu_s` / `mu_step` 是**两个独立的一阶扫描变量**；合并会让二维扫描静默降成一维（数字量级不变、不报错）。**任何覆盖表 / 敏感性表不得把这两行当作已有值**——本轮两行均为【待标定】。
- 仿真侧展开：`slide1 = slide2 = 该行 μ`；`spin` / `roll1` / `roll2` 不属于这两行 μ，必须在 pair 里显式写全，不得靠默认值（默认会把 `slide2` 掉回 `1.0`）。

## 9. 填写须知

- 每次测量记：日期、操作人、仪器编号、环境（T/RH/kPa/lx）、SoC（电压 + %）、`load_state`、原始文件路径。
- SoC 固定口径：满电后静置 30 min 再测；测量前后各记一次电压，差值 >0.2 V 作废重测。
- 数值位数不超过量具分辨力；不确定度保留 2 位有效数字，判定限用修约后的 `verified_tol`。
- 空值参与均值/统计前**必须显式跳过**，不许被 `pandas` 默认当 0 求和。任何汇总统计必须**同时报各自的 `n`**（有效样本数）与缺失计数，否则"均值"会在不同分母上被比较。禁止对数值列使用 `fillna(0)`。
- 外部来源行 `ref` 必须带 `source=<出处>; retrieved=<yyyy-mm-dd>; rev=<pin>`；三者缺一视为不完整，不得进入报告；没有 `rev` 不得引 `path:line`。
- 契约里"必须有"的字段，一旦某机型天然没有，实现方一定会编值。编出来的值不报错，只是让判据判在一个不存在的自由度上。所以遇到"该机型没有这个自由度"，正确动作是**声明没有 + 列置空 + 记不可判**，不是填一个能过判据的数。
- 贴图、截图若含厂商标识或受限尺寸，不入库。
