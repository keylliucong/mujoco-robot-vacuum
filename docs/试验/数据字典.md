# 数据字典（B 系字段 ↔ MuJoCo 参数）

- 版本：v1 · 2026-11-21 · 试验标定
- 用途：让交出去的时程与参数能直接对上验收项与模型字段，减少二次翻译。

## 1. 机体系 B

- B = world = chassis 局部系：+x 前进、+y 向左、+z 向上，右手系。
- 原点＝左右驱动轮轴心连线中点在地面的投影；z=0 在地面。
- 记录表表头标「B 系」；CAD 全局系换算给 (dx, dy, dz, ψ)。

## 2. 符号约定

| 量 | 约定 |
|---|---|
| `omega_wheel`, `torque_wheel` | 取绕 +y 分量后取负，前进/驱动为正 |
| 悬挂压缩 `s` | 压缩为正；`s_zero` 见记录表 §3 |
| 电机端 / 轮端 | 分列，`i_gear` 单列（电机端与轮端不得混用） |
| 接触力 | 法向 `Fn` 沿门槛/地面法向为正；切向 `Ft` 与滑移方向相反为正 |

### 3.1 容差口径（不可互换）

- CoM：±1 mm（长度量，按 §1 的 B 系原点换算后比较）。
- 惯量对角：本轮 `5–10%（有值即可；3% 另议）`。
- `3% 的取得路径见复核意见（转轴摆过质心，d ≤5 mm），不等同于收紧 com；契约口径待更新。`
- 惯量积：本轮按对称声明设 0（`Ixy = Iyz ≈ 0`；`Ixz` 在纯俯仰方程中不出现）；`I_xy/Izz` 由报告口径给出（派生量，非独立测量），台账不占行。
- **两者不可互换**：±1 mm 只对 CoM，不用于惯量；惯量不用长度容差。

## 4. 标签枚举与升档

| 标签 | 含义 | 可支撑的结论等级 |
|---|---|---|
| 本机实测 | 本机、本台架、按本模板测得，带 `u_c` | 可达 `quantitative`（`u_A` 三项齐、`u_B` 已评估、`u_sim` 齐） |
| 公开参考 | 文献/标准/厂商公开值 | 最高 `sensitivity` |
| 工程假设 | 无来源的取值假设 | 仅 `mechanism`/`sensitivity`，不得进定量结论 |
| 缺失 | 已知需要但还没有 | 该参数结论 ≤ `mechanism` |
| 待标定 | 本轮不测、下一轮补 | 该参数结论 ≤ `mechanism` |
| 【图纸推算】 | CAD/图纸推算值 | **默认止于 `sensitivity`**；逐行放行到 `quantitative` 必须带交叉校核，图纸尺寸单独进台账不足以升档 |

等级只有三档：`mechanism` / `sensitivity` / `quantitative`，**无 judgment**。参数行 `label` 定基档；结论等级还要看容差刻度是否齐备。

### 4.1 词表归属

| 位置 | 用词 | 取值 |
|---|---|---|
| 仿真摘要列名 | `outcome` | `cleared` / `blocked` / `invalid` |
| 失败分类 | `failure_mode` | 具体机理名（`lift_fail` / `slip_stall` / `belly_contact` …） |
| 验收限判定 | 只在验收限文档与签署记录里出现 | 不得进入仿真摘要 |

`pass` 在验收限语境里是判定级措辞，而仿真里的 `pass` 只是"这一次算例里机器人有没有爬上去"——**是结果不是判定**；同一个词两种含义，grep 会一起抓，评审也分不清。

- **机器侧**：`summary.csv` / `run.json` 的 `conclusion_level` **一律指结论等级**；**参数等级不入 `summary.csv`**，只从 `run.json.params[].label` 读。一张表只放一个等级。
- **文档侧**（报告与图注）：并列两列，列名写清来源：`参数等级（label）`、`结论等级（conclusion_level）`；不得只报其一。
- **文档双列 ≠ 机器双字段**；机器里只有一个等级字段，另一个从 `label` 读。

### 4.2 等级与分量状态（两套词，互不换算）

| 等级三档（结论） | 含义 |
|---|---|
| `mechanism` | 只有机理层结论 |
| `sensitivity` | 加上敏感性/方向性 |
| `quantitative` | 可用 `verified_tol` 做定量判定 |

| 分量状态三类（`u_B`） | 含义 |
|---|---|
| `evaluated` | 已评估，不降档 |
| `assumed` | 假设/经验，结论封顶 `sensitivity` |
| `pending` | 缺证书/量程/未测，结论封顶 `mechanism` |

**两套词互不换算**——`evaluated` 不是等级、`quantitative` 不是状态；任何文档不得出现「judgment 级」「evaluated 等级」这类跨表拼词。等级只有三档，`judgment` 这个词不存在。

### 4.3 `invalid` 四类（不得混进 `blocked`）

> 下列四类记 `invalid`，**不得混进 `blocked`**——混进去等于把"测坏了"记成"爬不上"：① 无接触（未真正接触门槛）；② 穿透超限；③ 蠕滑基线超标；④ `v_impact` 不同源。

`invalid` 必须**同时**给绝对数 `n_invalid / n_total` 与比例；只给百分比视为不完整。一组只有 4 个 case 时，"invalid 25%"与"invalid 1 个"读起来完全不同——百分比让人误以为有统计意义，绝对数让人立刻看出"可用批次只剩 3 个"。**不得与 `blocked` 合并成"失败率"**。若某组 `invalid` 占比过高，该组结论写"可用批次 n 不足"，不许悄悄摊薄。

## 5. 缺失 vs 待标定

- 缺失：现场/图纸/仪器哪一环没有，需说明缺哪一环。
- 待标定：本轮范围外、已排下一轮的测量项（如 μ、轮端扭矩、台架通过率）。
- 两者都不得填进实测列，也不得用文献值顶替。

## 6. 单位与舍入

- 表内按量具分辨力给位数；模型侧统一 SI。
- 不确定度保留 2 位有效数字；`verified_tol` 修约后再用于判定。
- 角度：表内 °，模型 rad（换算在导入脚本里做，不在表里做）。
