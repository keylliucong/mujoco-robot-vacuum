## 1. 判定口径（R-UNC-1）

- 判定限 = 规格限 ∓ `verified_tol`；单侧判据写「实测 ≤ 规格上限 − `verified_tol`」。
- `verified_tol = k·u_c`，`u_c = √(u_A² + u_B²)`；k=2，ν_eff<10 用 t(0.975, ν_eff)。
- 比对判定 `u_c,cmp = √(u_meas² + u_sim²)`；`u_sim` 缺项则不出判定。
- 容差不并入规格限本身。

## 4. 未覆盖项（本轮，冻结时必须原样保留）

- A3 轮端扭矩、A4 轮–地/轮–铝门槛摩擦、A5 台架通过率曲线：本轮不出数，记「下一轮」。
- 后果：本轮任何通过高度结论封顶机理 + 敏感性，**不冻结定量通过高度**。
- 因此本冻结稿只冻结：定性判据 + 拟合集标定报告口径（含参数边界与不确定度）+ 数据集划分。

> 配重只复现 m 与质心，不复制惯量——真实尘水是摊开的，配重块是集中的。因此配重法只对「准静态通过高度」负责，不对「冲击峰值力、接触力时程、翻越瞬态」负责。
