## 1. 判定口径（R-UNC-1）

- 判定限 = 规格限 ∓ `verified_tol`；单侧判据写「实测 ≤ 规格上限 − `verified_tol`」。
- `verified_tol = k·u_c`，`u_c = √(u_A² + u_B²)`；k=2，ν_eff<10 用 t(0.975, ν_eff)。
- 比对判定 `u_c,cmp = √(u_meas² + u_sim²)`；`u_sim` 缺项则不出判定。
- 容差不并入规格限本身。
- 方法有效性条件见 §5 A1–A4。
- 相对容差只用于可脚本判定的情形：**`|value| < 10 × verified_tol` 时禁止用相对容差口径**，改用绝对口径；惯量对角 5–10% 等相对量必须先过这一条。

> **参数行等级**（台账、`run.json.params`）：只看 `label`，回答"这个数从哪来"。
> **结论等级**（如通过高度这类派生结论）：看「参数标签 **且** 容差刻度」，回答"这句话能说到多远"。
> 细则：参数全【本机实测】**且**比对该用的 `verified_tol` 齐备 → 结论可 `quantitative`；有 `pending` 分量 → **结论**封顶 `mechanism`；有 `assumed` 分量 → **结论**封顶 `sensitivity`。**参数等级不受影响。**

> 【图纸推算】三元组齐了也**只到 `sensitivity`**，不自动升 `quantitative`；升档仍要逐行实测交叉校核：`verified_by=<实测 param_id> @ <sha>`，且 `|delta| ≤ verified_tol`。

- 有 `pending` 分量的参数，其 `verified_tol` **必须为空**——容差没有刻度就不许填数，**不许用 0 或估计值占位**。

> 下列四类记 `invalid`，**不得混进 `blocked`**——混进去等于把"测坏了"记成"爬不上"：① 无接触（未真正接触门槛）；② 穿透超限；③ 蠕滑基线超标；④ `v_impact` 不同源。

`invalid` 必须**同时**给绝对数 `n_invalid / n_total` 与比例；只给百分比视为不完整。一组只有 4 个 case 时，"invalid 25%"与"invalid 1 个"读起来完全不同——百分比让人误以为有统计意义，绝对数让人立刻看出"可用批次只剩 3 个"。**不得与 `blocked` 合并成"失败率"**。若某组 `invalid` 占比过高，该组结论写"可用批次 n 不足"，不许悄悄摊薄。

> 跨机型属于**配置问题**，单独记 `excluded: cross_machine`，**不并入 `invalid`、也不并入 `blocked`**。若某批扫描用的是基准机型（`machine=oomwoo`）的几何/质量属性，而结论写给自己机型，**该批数据无效**，且不得计入任何组。
- 出处栏为空时，报告只能写「按本方案 `A1`–`A4`」。**「参考某标准」「参照某标准」「借鉴某标准」一律不许写**——那是同一个问题的软版本，读者照样会以为有依据。允许出现的标准号仅限：已在差异表登记条文号、且原文关键句已记入本地私有摘录（不入库）的条目。

> 本版冻结的是**判据形式与判定流程**（`A1`–`A4` 的式子、`u_A/u_B/u_c/verified_tol` 的算法、`∓ verified_tol` 的判定方式）。其中的参数化阈值（如 `A2` 的 `min(0.5 mm, 5%·travel)`、`A1` 的查表值）**按式代入**；代入后判据变严或变宽都不算变更，但报告必须报出代入的实际数值与该批是否可用。`travel` 未测时 `A2` 判为不可判、该批不可用，这不是改冻结，是按冻结执行。

> 因本轮多数 `u_B` 分量 `status=pending`，`u_c` 不完整 → `verified_tol` **不可算**。故本轮：
> - **执行** `A1`–`A4` 做批次有效性筛选（这四条不依赖 `u_c`）；
> - **不执行** guard-band 通过判定；
> - 报告给「逐批读数 + 是否满足 A1–A4 + 结论等级 mechanism」，`verified_tol` 栏统一填 `不可算（u_B pending）`，判定栏统一填 `N/A（u_B pending）`。
>
> 本轮数据**不得**与任何 guard band 比较，也不得用于"是否通过某高度"的定量结论。

> **「不判定」读起来像我们选择不判、暗示"判了可能会过"；`N/A（u_B pending）` 读起来是前提缺失，谁都不能把它当宽松阈值。**

- 本轮报告模板**不设「通过」列**——没有列就没有人填；只有结构必须保留（对接既有脚本/表头）时才保留该列，值一律 `N/A（u_B pending）`。
- 结论与正文禁用：`通过高度`、`可通过高度`、`最大越障高度`、`临界高度`、`极限高度`、`通过 X mm`、`合格`、`满足标准`。

> 允许的替代表述示例：在 `Δh=25 mm`、`v_impact=0.071 m/s`、`A1`–`A4` 均满足的 3 个批次中，**观察到整车越过**；第 4 批因 `A2` 不满足按不可用处理。读数见附录。

> **措辞上留一个口子，等于把 `N/A` 又变回判定。**
- 本轮判据以**低速准静态接近**为前提（数值判据待仿真专家确认，候选 v ≤ √(0.02·g·Δh)，Δh=30 mm → 0.077 m/s，标【工程假设】；出处待定，待最终取得越槛标准原文后核对）。
- **第一层 整车平移**：判据用 `v_impact`（触槛瞬间速度），阈值按 Δh 查下表。
- **第二层 悬挂**：过槛期间悬挂压缩量相对同一批次静态平衡位的最大偏差 `< min(0.5 mm, 5%·travel)`（取严）；接近段加速度 `≤0.05 m/s²`（速度恒定）。未测出 `travel` 的批次该项不可判 → 该批不可用。
- 仅速度满足、悬挂被判激励的批次，即使 `v_impact` 在表内，也按不可用处理，单列并注原因。

> 实测质心与模型 CoM 均按 §1.1 的 B 系原点换算后比较，±1 mm 在该参考点下成立。

1. **±1 mm 只对 CoM（长度量）。** 惯量用试验方案既定容差（对角 `5–10%（有值即可；3% 另议）`；惯量积本轮按对称设 0 结案），两者不可互换；

## 5. 方法有效性条件

> `A1`–`A4` 的数值来自本方案（`A1` 由 `½mv²/(mgΔh) ≤ 1%` 推出），不依赖任何标准条文。因此出处待定**不影响 A1–A4 执行**；但报告**不得声称"按某标准"**——出处栏为空时，报告只能写"按本方案 A1–A4"。

> 正文引用一律用 A1–A4 定位号；标准条号只在出处栏出现。

> 出处栏为空时，报告只能写「按本方案 `A1`–`A4`」。**「参考某标准」「参照某标准」「借鉴某标准」一律不许写**——那是同一个问题的软版本，读者照样会以为有依据。允许出现的标准号仅限：已在差异表登记条文号、且原文关键句已记入本地私有摘录（不入库）的条目。

| 编号 | 条件 | 阈值 |
|---|---|---|
| `A1` | 整车平移准静态 | `v_impact ≤ √(0.02·g·Δh)`（Δh=20/30/40/50/60 mm → 0.063/0.077/0.089/0.099/0.109 m/s） |
| `A2` | 悬挂准静态 | 过槛期间压缩量相对同批静态平衡位最大偏差 `< min(0.5 mm, 5%·travel)` |
| `A3` | 接近段速度恒定 | 加速度 `≤0.05 m/s²` |
| `A4` | 扭矩无阶跃（电流代理） | 20 ms 均值后 `(I_f,max−I_f,min)/I_f,mean ≤5%` 且相邻窗均值差 `≤10%·I_f,mean` |

- 四条都是**方法有效性条件**，归验收限，不进契约、不 backlog、不受冻结。
- 报告里引用一律带编号：**「判悬挂准静态的依据见验收限 §5 A2」**，不写"见验收限第 X 条"这类会漂的指代。
- `travel` 是批可用性的前置量（`A2` 阈值 `min(0.5 mm, 5%·travel)` 依赖它），**D1 必须测出**；未测出 `travel` 前该批 `A2` 记 **`invalid（unmeasurable）`**、整批按不可用处理，**不得事后补测推定**——事后补的 `travel` 等于用后验知识判前验批次，该批数据的有效性论证就断了。
- 机型声明 `has_suspension=0` 时，`A2` 判 **`N/A（none，该机型无此自由度）`**——不是通过、不是失败。判据不适用，不等于判据被满足。

| 取值 | 含义 | 批次是否可用 |
|---|---|---|
| `N/A（none）` | 该机型**没有这个自由度**（`has_suspension=0`） | **可用**（判据不适用） |
| `invalid（unmeasurable）` | 该机型**有这个自由度但测不出**（`travel` 未测、位移采集失败） | **不可用** |

**双向矛盾检查**（两条都查）：

- 出现 `N/A（none）` 但模型 `has_suspension=1` → **矛盾**；
- 模型 `has_suspension=0` 但 `susp_*` 任一行有值（含 0）→ **矛盾**。

> 契约拦得住等级与数据形状，拦不住人拿一个合法的 `quantitative` 去说它没说过的话；这一层只能靠本条措辞与报告审读。

### 5.2 作图规则（G6）

1. 散点图纵轴为**类别轴**：固定三行 `cleared / blocked / invalid`，横轴 `Δh`；无比率纵轴。
2. 点形**形状+填充双编码**（黑白打印与色弱都要能分）：`cleared` 实心圆、`blocked` 空心圆、`invalid` 小号 ✕ 浅灰。
3. `invalid` 单独一行、**永不并入 `blocked`**，图例写"不计入任何统计"。
4. 分面顺序 `0° → +15° → −15° → +30° → −30°`（`|heading|` 升序，同值内 `+` 在前）；左右不合并。
5. `n` 写在 panel 标题里，格式：`heading = +15°，n = 3（cleared 1 / blocked 1 / invalid 1）`。
6. `blocked` 点在组内 ≤8 个时点旁标 `failure_mode` 短标签；>8 个移到附录表。
7. **主图分图不分 panel**：G6-a 正对组、G6-b 小 n 斜向组各自独立成图，**不许同页并排**（并排就是视觉比较）；G6-b 首页脚注写「各点 n 极小，仅示个案，不表示概率或趋势」。

- 区间带只画 `h_cleared,max` 与 `h_blocked,min` 两条，中间浅阴影标「未分辨区间，不插值」。
- 图例文案逐字：`● cleared（越过）　○ blocked（未越过）　✕ invalid（数据无效，不计入任何统计；含无接触、穿透超限、蠕滑基线超标、v_impact 不同源）`。
- **本轮不出现任何比率曲线与百分比（含大 n 组）**：比率是估计量、散点是观测；`n=20` 的二项 95% 区间约 ±22%，画成曲线会被当趋势读。报计数不报比率：写「4 例中 3 例 `cleared`」，**不写「75%」**。

### 5.3 `z_cg` 的处理

> **`z_cg` 是一阶变量。** 本机型的 `z_cg` 未实测前：
> - **不许用 BOM 零件位置"凑"一个 `z_cg` 当基准**——那会让整张敏感性表的横轴错位；
> - 本机型**优先实测**（记录表已有测点，目标 2 mm）；
> - 仅当对象是**基准机型（`machine=oomwoo`，无 CAD、无法实测）**时，才在 G5 里把 `z_cg` 当**扫描变量**；
> - 凡以 `z_cg` 为横轴的结论，只能写「扫描范围内」，**不得写单点值**。

- 区间写法：`z_cg ∈ [0.25·H, 0.55·H]`，`H` = 整机高度（实测）。
- 依据：底盘重心偏低、电池与驱动单元在下部——**标【工程假设】**，并备注"区间由整机高度比例给出，未经实测复核"。
- **区间外翻的处置**：若扫描发现结果在区间端点上已经翻转，说明该端点不足以覆盖，**扩区间重扫**，并在报告写明"原区间端点已翻转"；不得只报区间内的结果。


### 5.1 扫描纪律（G3 全部扫描项）

- 扫描区间一律 **`0 → 上界`**，不写 `±50%` 之类围绕标称值的对称区间。
- 上界定义：`min(物理上界, 3×当前假设值)`；取哪个、为什么，写在该参数行的 `note` 里。
- **`I_att` 的上界**：`I_att,max = m_att · k_max²`，`k_max` 取机身最大半尺寸实测值；`I_att,max` 算出来若低于几何推算值，说明推算有误，**退回重推，不调上界**。
- 本轮适用参数（都还没有实测值）：`I_att`、`μ_s`、`μ_step`、`k_susp`、`F_limit`。
- **报告措辞纪律**：只许写「**在扫描区间内未翻转**」；不许写「该参数不敏感」「影响可忽略」这类把"区间内"偷换成"普遍"的说法。
- `0` 是这几项的物理真下界（无附加惯量、无摩擦、无刚度、无限位力），所以必须包含。
