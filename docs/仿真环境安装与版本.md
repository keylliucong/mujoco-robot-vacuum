#### 蠕滑基线与数值设置

- 2 ms 静置 1.5 s、测量 1.0 s、观察 10 s：`mean_speed=4.27e-13 m/s`，`drift=2.38e-14 m`；均低于 1 mm/s 与 0.5 mm，未触发降步长（`timestep_downgraded=false`）。
- 生效 `<option>`：`timestep=0.002`、`integrator=implicitfast`、`cone=pyramidal`（elliptic 批次为 `elliptic`）、`solver=Newton`、`iterations=100`、`tolerance=1e-8`。`condim=3`，未升维。
- 接触参数、摩擦、`solref/solimp` 仍为工程假设/待标定；所有参数在 `run.json.params` 中逐项带标签，`conclusion_level=mechanism`。

#### 锥型对照发现

同一配置、同一提交下，`pyramidal` 与 `elliptic` 的 outcome 出现差异：

- `step_fwd_10mm_std`：pyramidal `cleared`，elliptic `blocked / timeout`（elliptic 的 `advance_m=1.152`，但两轮未同时达到登台高度判据）。
- `step_obl_p30` / `step_obl_m30`：pyramidal `blocked / timeout`，elliptic `cleared`。
- `step_fwd_10mm_qs`：pyramidal 无轮-台阶接触（A1 na），elliptic 有轮-台阶接触且 A1 为 `met`（v_impact=0.0325 < 0.0443），但两者都 `blocked / slip_stall`。

因此本轮只能给出机理与敏感性结论；锥型未收敛前，不用单锥结果声明越障能力。两种锥型的 `summary.csv` 与 `run.json` 均在 `docs/验证输出/`。

#### 结构与参数限制

- 基准机型 oomwoo 没有可信整机 CAD/STEP；几何来自 `makerspet/oomwoo-one` 的 URDF（公开参考）。`device_full.step` 按上游 README 明确不是 OOMWOO One 设计，未使用。
- 首版 MJCF 把轮胎简化为球体（接触稳健；轮宽/胎面不建模），把底盘保险杠分片简化为圆柱，并新增后从动支撑用于数值稳定；这些是结构简化/工程假设，不是 oomwoo 的公开结构。
- 驱动轮/从动支撑的悬挂按 0 行程固定铰处理；A2 不适用。悬挂行程、刚度、阻尼、限位需实机试验后启用。
- 质量、质心、惯量：质量与几何为公开参考，惯量为公开几何的解析推算；整机称重、悬挂法质心、摆动/扭摆惯量均未做。摩擦、接触参数、扭矩-转速曲线均未标定。
- 本轮结论封顶 **机理 + 参数敏感性**，不构成产品越障能力或验收结论。
