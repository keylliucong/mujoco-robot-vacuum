# 扫地机器人越障动力学仿真｜Phase 1 资料检索清单

## 给执行 Agent 的任务

为后续 MuJoCo 整机动力学建模查找可追溯的资料。回答三个问题：扫地机如何越过门槛，哪些参数会影响通过与失效，有哪些台架或实机数据可以用来校准和验证仿真。本阶段交付资料、证据和缺口清单。

暂以硬质门槛或单级台阶为首轮工况，包含正向与斜向接近，以同一地面上的平地行驶为对照。软地毯边缘和多级门槛作为后续扩展。目标机型、结构和门槛尺寸待项目资料确认，公开竞品数据按对应机型和测试条件记录。

- [x] **查扫地机越障机构。**（已检索，见证据表第 2 节） 优先找专利全文、厂商技术资料、拆解与原始视频。按被动轮组摆臂或弹簧悬挂、主动抬升底盘或轮组分别整理，记录接触顺序、机构自由度、限位和驱动方式。专利附图与量产结构的对应关系单独标注。关键词：`扫地机器人 越障 驱动轮 摆臂 弹簧`、`扫地机 主动抬升 门槛 专利`、`robot vacuum threshold climbing suspension`、`robot vacuum active chassis lift patent`。
- [x] **查轮式机器人台阶动力学。**（已检索，见证据表第 3 节） 用 Google Scholar、Crossref 或学校数据库追到论文原文。提取轮径与台阶高度关系、重心和载荷转移、轮与边缘接触、打滑、驱动扭矩及斜向越障时左右轮先后接触的分析。记录每个模型的假设，以及可从原文复现的算例或试验。关键词：`wheeled mobile robot step climbing dynamics`、`wheel step obstacle climbing torque friction`、`wheeled robot oblique step climbing experiment`。

## 交付与验收

1. **检索日志与证据表。** 保留数据库、检索词和检索日期。每项结论附 DOI、专利号或原始链接，标明页码、图表号或视频时间戳、测试条件和适用机型。遇到数值冲突时并列来源与条件。厂商标称越障高度按声明条件录入，并注明实测证据是否可得。
2. **仿真参数表。** 每行包含参数、单位、数值或区间、条件、来源、适用性和补测方法。标记本机实测、公开参考、工程假设或缺失。
3. **基准工况与数据缺口。** 列出平地、正向台阶、斜向台阶三类工况的输入、通过判据、可对比输出和已有证据。若找不到可复现的原始数据，保留检索记录，并明确缺少哪项测量才能验证该工况。

每个检索主题都应有可复查的来源或明确的缺口记录。交接时指出最影响首版模型可信度的输入和应优先补测的项目。
