## 1. IEC 62849:2025 §6.1 门槛越障（threshold overcome）

### 1.1 章节结构（照整理稿）

| 条号 | 标题 | 本文件对应小节 |
| --- | --- | --- |
| 6.1 | General | §1.1 |
| 6.1.2 | Test equipment | §1.2 |
| 6.1.2.1 | 基本试验台 | §1.2「试验台基础配置」 |
| 6.1.2.2 | 附加设备（门槛） | §1.2「三种类型」「材质与安装」 |
| 6.1.3 | Test method | §1.3、§1.5 |
| 6.1.3.1 | （自动模式，整理稿中标为试验步骤） | §1.3 |
| 6.1.3.2 | 手动模式 | §1.5 |

> 整理稿对 6.1.3 的下一级只给出「自动模式 / 手动模式」两段；条文原文的分段与编号须正版核对。

### 1.2 ① 门槛几何（§6.1.2.2 + 表 3）

**三种类型（表 3）**

| 类型 | 截面几何 | 测试高度 h |
| --- | --- | --- |
| 圆柱形 | 圆形面 | **h ＝ 直径** |
| 矩形 | 宽 40 mm，**顶缘半径 R3**，高度可变 | 高度可变 |
| 梯形 | 顶边 40 mm，**底角 40°**，高度可变 | 高度可变 |

（图 1 为三种门槛形状的图块，见图；本仓库未复制。）

**材质与安装**

- 材质：**铝制**；表面**未打磨 / 未处理**。
- 长度：**≥ 2150 mm**。
- 安装：固定于行走面；机器人碰撞时**不得向任何方向移动**（不得滚动、不得弯曲）。

**试验台基础配置（§6.1.2.1）**

| 项 | 要求 |
| --- | --- |
| 试验台平面尺寸 | **≥ 4000 mm × 2150 mm** |
| 四周墙高 | **≥ 300 mm** |
| 天花板高度 | **≤ 3500 mm** |
| 地板 | **未处理层压松木板，厚 ≥ 15 mm** |

### 1.3 ② 试验步骤（§6.1.3.1 自动模式）

| 项 | 整理稿要点 |
| --- | --- |
| 起始位置 | **3 个**：S1 / S2 / S3；角度公差 **±5°**；起始朝向见**图 4**（图块见图，未入仓） |
| 计时 | **5 分钟** |
| 「到达另一侧」定义 | **移动底座整个身体**越过门槛；**不含手臂等**其它部件 |
| 结束条件 | ① 到达另一侧；② 停止运行且 5 分钟内未继续任务；③ 5 分钟内未到达另一侧 |

### 1.4 ③ 通过判据与重复次数

- 每个起始位置**连续 3 次 trial** 均到达另一侧 → 判定**该高度可通过**。
- **逐档调高**门槛高度，确定**每种形状**的最高可通过高度。
- 若机器人具备「**避免攀爬特定高度 / 特定形状**」的功能（即主动跳过某类门槛），**须在报告中声明**。

### 1.5 ④ 手动模式（§6.1.3.2）

- 起始：距门槛 **1 m**、**正对门槛**开始。
- 采用**结构化搜索**，初始参数 **h₀ ＝ 17 mm**。
- 计时：**5 分钟**结束。
- 通过判据：**门槛两侧各连续 3 次**到达另一侧。

## 2. IEC 62849:2025 §6.4 最大坡角（maximum slope angle）

> 整理稿标注：这是**唯一**的标准坡角试验方法（相对本项目已检索到的标准集合）。

### 2.1 章节结构

| 条号 | 标题 |
| --- | --- |
| 6.4.1 | General |
| 6.4.2 | Test equipment |
| 6.4.3 | Test method |
| 6.4.4 | Test results |

### 2.2 坡道几何（§6.4.2）

| 部件 | 规格（照整理稿） |
| --- | --- |
| 坡道 | **可调角度**；倾角精度 **±0.5°** |
| 底座 | **1000 mm × 1000 mm**，**未处理层压松木**；四周 **300 mm 高墙** |
| 坡道板 | **1000 mm × 1000 mm × 20 mm**，**未处理层压松木** |
| 平台 | **1000 mm × 1000 mm × 20 mm**，**未处理层压松木**；四周 **300 mm 高墙** |
| 过渡板（坡道—平台） | **2000 mm × 1000 mm × 1.5 mm 铝制**；坡道与平台之间**须有中间弯折（折叠半径 R3）**，弯折角与测试角一致 |
| 过渡（底座—坡道） | **不可折** |
| 测试角度范围 | **3°–15°**；按制造商手册报告或要求的角度测试（整理稿未表述为强制全序列） |
| 安全 | 坡道**两侧须加保护墙**；**测试开始前装好，开始后不可更改** |
| 台面附加 | 可按需铺**整块地毯**；**不得拼接** |

### 2.3 试验步骤（§6.4.3）

| 项 | 整理稿要点 |
| --- | --- |
| 适用对象 | **仅适用于自主运行**的机器人 |
| 1 次试验的定义 | 从**底座**跑 1 次 ＋ 从**平台**跑 1 次＝**2 run** |
| 放置 | 机器人置于底座或平台**中央**，**正对坡道** |
| 启动 | 按**制造商说明**启动自主运行 |
| 通过条件 | **5 分钟内**到达对面平台**且能继续正常运行** → 停止、记录 |
| 判退条件（5 分钟内任一） | ① 卡住 **30 s** 内无法移动；② 从坡道**跌落**（即使仍能正常工作）；③ **翻倒**（即使仍能正常工作）；④ 5 分钟后**仍在起始侧运行** |

### 2.4 重复次数

- 共 **3 次试验**。
- 一个坡角的完整试验＝**3 次试验 × 2 run ＝ 6 次 run**。

### 2.5 通过判定（§6.4.4）

- 一个坡角**当且仅当全部 6 次 run 均通过**才算通过。
- 结果按**表 4** 记录：**3° / 6° / 9° / 12° / 15° × 上坡 / 下坡**，逐格记录。

### 2.6 坡上速度（整理稿明确的范围说明）

- 本标准**不测坡上速度**，只判定「**能否在 5 分钟内通过**」。
- §1 范围把机器人**最高速度限定为 1.5 m/s**——这是**适用性约束，不是性能指标**。
- 如需坡上速度，**只能作为工程附加测量项**，不属本标准要求。

## 5. 已排除与同源关系

**已排除（整理稿称经全文检索，均无越障专项测试方法）**

- GB/T 34454-2017
- IEC/ASTM 62885-7 的其它章（除 §6.4.5 / §9.2.5 外）
- IEC 60335 系列
- IEC 60730
- IEC 62885-2 / 62885-5 / 62885-6

**同源关系（整理稿原话）**

- 62885-7 的门槛方法被 62849 在 **§6.1.2.1 注记**为「试验台配置与该标准 **9.2.1** 相同」；二者**公差体系一致**，属**同源方法**。
- 因此 §3 可作为 §1 的几何/台架交叉印证，但**不能**据「同源」把两份标准的判据互换，也不能据此写成符合性结论。
