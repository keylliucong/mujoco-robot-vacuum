# 决策记录（ADR）

一条决定一节，编号 `D-01` 起。每条固定四段：**决定 / 依据 / 影响 / 翻案触发条件**。

只记决定与理由，不记测量值。条文细节指向 `docs/契约/` 与 `docs/试验/`，本文件不复制。

## D-01 本轮数据口径

**决定**

轮端扭矩、轮–地与轮–铝摩擦、台架通过率曲线（A3/A4/A5）本轮不做实测，按扫描参数处理，记为下一轮。

**依据**

机型侧四项 P0 缺失。

**影响（谁要改什么）**

本轮任何通过高度结论封顶「机理 + 敏感性」，不给定量通过高度。仿真侧按扫描参数出结果；试验侧不排这三项实测；报告写法统一改为封顶表述。

**翻案触发条件**

机型侧四项 P0 补齐并完成实测后，下一轮重新评估是否解除封顶。

## D-02 越障负载口径

**决定**

- 主口径 = 空载，填充集全用空载。
- 辅口径 = 刚性等效配重（质量 = 尘 + 满水，质心落在实测满载质心）。
- G6 第二条线在交叉校核前只能叫「配重下界」；升档为「满载静态下界」需三条同时满足：密封满水实测 `m` 与质心、配重落点 ±1 mm 复称验证、记录含排气法与密封结果。
- 真实尘 + 满水只作最终验收旁证，不进拟合。

**依据**

质量一阶相消（需求 ∝ m·g、附着极限 ∝ μ·m·g），质心位置才是一阶敏感；满水自由液面会晃荡。

**影响（谁要改什么）**

仿真侧填充集统一跑空载，配重线单独标注「配重下界」；试验侧按三条升档条件准备记录；报告与图注不得把配重结果直接称为满载。

**翻案触发条件**

三条升档条件全部满足并通过交叉校核，可升档为「满载静态下界」；若密封或排气记录不成立，回落为「配重下界」。

## D-03 满载静态口径

**决定**

水箱满水、排净空气、封盖；尘盒装满并压实、封盖。无自由液面即刚体，倾斜/多支点法成立。

禁用：用水箱几何质心、自行引入 80% 水位。

**依据**

测不准的原因是箱内空气，不是水是液体。

**影响（谁要改什么）**

试验侧按此准备满载件并记录排气与密封；任何人不得以几何质心或 80% 水位替代实测；仿真侧只接受按此口径测出的 `m` 与质心。

**翻案触发条件**

出现可复核的证据表明箱内空气无法排净且该残气对质心的影响不可忽略。

## D-04 判定容差

**决定**

- `verified_tol = k·u_c`，`u_c = √(u_A²+u_B²)`，`k` 默认 2（`ν_eff<10` 用 t 分布）。
- `u_A` 三项含 `s_day`（≥3 日/批复测）。
- 纯重复性 3σ 降为诊断列 `diag_3sigma_A`，不参与判定。
- `u_B` 分量清单为交付物，空即未评估。
- 判定限 = 规格限 ∓ `verified_tol`。

**依据**

判定门不能窄于流程自身复现性。

**影响（谁要改什么）**

试验标定出 `u_A`/`u_B` 并交付分量清单；判定脚本按 `verified_tol` 计算判定限，不再用 3σ；报告引用 `quantitative` 时必须同时给出 `verified_tol`（契约 §4）。

**翻案触发条件**

`u_B` 分量清单缺失或未评估时，该参数不得进入判定；若方法学变更导致 `u_A`/`u_B` 定义变化，先改契约 §6 R-UNC-1 再改本条。

## D-05 契约冻结

**决定**

契约冻结点 v1.7（`contract/g2-interface`，PR #5 draft）。冻结期只许「澄清」与「删规则」，不许加字段/加枚举/加列。开版只三种触发：证明不可实现或自相矛盾、backlog 触发条件满足、P0 实测推翻假定。backlog 每条必须带触发条件。

**依据**

**影响（谁要改什么）**

架构师维护冻结状态与 backlog；G2 实现方按冻结版实现，遇到缺口只提澄清，不提加字段；任何开版请求必须写明属于三种触发中的哪一种。

**翻案触发条件**

满足上述三种开版触发之一，且 backlog 条目已写触发条件。

## D-06 判据出处

**决定**

本轮判据方法学用 **GB/T 38124-2019 §5.1.5**（免费全文可核）；IEC 62849:2025 §6.1.3、GB/T 38834.1-2020 本轮不采购、不引原文。差异表必须逐项写「GB/T 规定值 / 未规定 / 未知」，不许默认等同、不许留空。IEC 62849 适用范围排除干湿清洁机器人，只可写「借用其通用移动性试验方法的意图」，不得写「符合」。

**依据**

**翻案触发条件**

取得 IEC 62849:2025 或 GB/T 38834.1-2020 正式全文并完成逐条比对。

## D-07 惯量

**决定**

- 空载惯量必测（P0 之一），精度 5–10% 即有值即可。
- 载荷附加惯量本轮不做实测（惯量不进准静态判据，条件方程里无 I 项），台账留【缺失】行。
- G5 用 k 档扫描（`k = 0 / 0.5·k_ref / k_ref / 1.5·k_ref / k_max`）判「配重安装位置是否不敏感」。
- 惯量积按对称设 0 结案，仅对正对 + 纯俯仰成立。
- 测量缺省用过质心测法（轴过质心、d ≤ 5 mm）。

**依据**

系数与容差传播。

**影响（谁要改什么）**

试验侧把空载惯量列入必测；台账为载荷附加惯量保留【缺失】行（契约 S21 成套性要求）；仿真侧 G5 跑 k 档扫描，不得把对称假设外推到斜向或横滚。

**翻案触发条件**

空载惯量实测精度达不到 5–10%，或需要把惯量纳入判据、或需要斜向/横滚工况的惯量积时，重新评估是否补测载荷附加惯量与惯量积。

## D-08 准静态判据 A1–A4

**决定**

- **A1**：`v_impact ≤ √(0.02·g·Δh)`（Δh=30 mm → 0.077 m/s，标【工程假设】）。
- **A2**：过槛期间悬挂压缩/回弹相对静态平衡位偏差 `< min(0.5 mm, 5%·travel)`。
- **A3**：接近段加速度 ≤0.05 m/s²。
- **A4**：扭矩无阶跃，本轮用电流代理（20 ms 滑动平均，波动 ≤5%、相邻窗差 ≤10%），并标明代理关系未标定。

适用范围：整车平移与悬挂两自由度均为准静态，且 `v ≤ 0.077 m/s`；不等于产品实际使用条件下的越障能力。

**依据**

【待确认】（本轮派单未给依据原文；A1 的 0.02 系数与 Δh=30 mm 已标【工程假设】，A4 的电流代理关系未标定）。

**影响（谁要改什么）**

仿真侧接近速度与驱动输入受 A1/A3 约束；试验侧按 A1–A4 设采集与判读窗口；报告必须写适用范围，不得把准静态结论当作产品实际越障能力。

**翻案触发条件**

A4 电流代理完成标定，或实测表明 A2 的量测分辨率达不到 `min(0.5 mm, 5%·travel)`。

## D-10 台账纪律

**决定**

- 口径走 `ref` 保留痕、不加列。
- 换口径加新行并标 `superseded_by`，不改旧值。
- `derived_from` 引用的行必须同属（`payload_state`, `config_id`）分组。
- 「复算」（`role=derived`）与「互校」（`role=check`，须独立原始文件）两词分开。
- 配重 0.50 kg 设计点只挂【工程假设】，不得作为边界条件引用。

**依据**

单一来源与可追溯性；复算与互校混用会把恒真式当校核证据。

**影响（谁要改什么）**

所有写台账的人按此执行；口径变更只能新增行并留 `superseded_by`；报告不得把 `role=derived` 的行称为互校；配重 0.50 kg 不得进入边界条件或结论引用。

**翻案触发条件**

契约 S21 或 §6 R-UNC-1 对台账结构作出变更时，本条随之更新；除此之外不改判。

## D-13 契约键形三段化

**决定**

`param_id = <machine>.<config_id>.<量名>`；`config_id` 与 `ref` 逐字一致、不得含点。

**依据**

同一载荷可有两种实体配置（`sealed_full_water` / `equiv_ballast`），两段键会撞键。

**影响（谁要改什么）**

台账 309 行、预算 43 行、8 个参数集、S23 已实现，统一按三段键形引用。

**翻案触发条件**

若出现第三种需要区分的配置维度，需另加段而非复用 `config_id`。

## D-14 G2 收口条件与三条适用限制

**决定**

G2 通过（结构 M1–M5 闭环、物理侧机理级通过/定量待标定）；该通过为有条件结论，对外引用必须同时带三条适用限制。

**依据**

三条限制即结论成立的边界：① 结论只在 `h=2 ms ∧ solref=0.01 s` 单点成立；② 依赖 500 Hz 控制带宽（控制周期 2 ms 过、20 ms 不过，末帧横移 2.02 m）；③ 准静态接近 `v ≤ 0.077 m/s`。超出上述边界的部分未被验证。

**影响（谁要改什么）**

对外引用 G2 通过结论时必须逐条带出三条限制，不得省略，不得把结论外推到其它步长、控制带宽或接近速度；物理侧定量结论一律标注「待标定」。

**翻案触发条件**

完成 solref 标定并做控制周期敏感性后重写。

## D-15 G3 结论：时步敏感且未收敛

**决定**

G3 结论为时步敏感且未收敛：控制周期固定 20 ms 后，2/1/0.5 ms 三档仍不一致，判为接触刚度—步长耦合；G3 出口写成「适用范围声明」而非「通过」。

**依据**

控制周期固定 20 ms 后，2/1/0.5 ms 三档结果仍不一致，表明接触刚度与步长耦合。

**影响（谁要改什么）**

G3 出口写成「适用范围声明」而非「通过」；下游不得混入 1/0.5 ms 数据。

**翻案触发条件**

`solref` 按 `2×timestep` 以上标定后重跑三档。
