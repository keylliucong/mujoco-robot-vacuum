# 项目状态与决策

## 这个目录是什么

本目录是项目状态、口径裁定与里程碑决策的**唯一权威落盘处**。凡是「项目现在到哪一步」「这条口径算不算定了」「这个 Gate 过没过」，以本目录的文件为准；别处的转述、总结和聊天记录都不具备权威性。

本目录只记**状态与决策**，不复制条文、不记数据、不写测量值和技术结论本身。

## 谁维护

- **Program-leader**：派单，确定哪个 Gate、哪条口径需要落盘。
- **架构师 / 仿真专家 / 试验标定**：出结论并给出依据，对内容负责。
- **执行 worker**：落笔，按派单写入本目录，不改判结论。

## 什么时候更新

- 每个 Gate 出结论时（通过 / 未通过 / 有条件通过）。
- 每次口径裁定或改判时（含翻案）。
- 每次里程碑或负责人变动时。

更新与代码、文档改动一样走分支和 PR，不直接改 `main`。

## 与其它文档的关系

- `docs/契约/`：接口契约与结构规则（schema、输出列、台账规则、扩展点）。**条文以契约为准。**
- `docs/试验/`：试验方案、记录表模板、数据字典与验收限。**验收限以试验文档为准。**
- 本目录：只记「定了什么、为什么、谁要改什么、什么条件下翻案」，以及 Gate 与在办事项的状态。**不复制上述文档的条文**；需要条文时写指针（条号 / 验收限编号 / 决策编号），不抄正文。
- `docs/仿真参数表.md` 等参数文档记录数值与来源标签，本目录不记数值。

## 一条硬规则

**任何裁定在落进本目录之前不算项目决定。** 只存在于对话、会议或某个人记忆里的结论，一律视为**未决**，不得被引用为依据，也不得据此改代码、改契约或对外汇报。要让它生效，就按上面的流程写进本目录。
