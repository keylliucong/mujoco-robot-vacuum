# 扫地机器人越障动力学仿真 PRD

## 目标与用户

为结构和仿真工程师建立可重复运行的 Windows MuJoCo 工作流，回答扫地机器人在什么工况下能越过门槛，以及打滑、托底、悬挂触底和驱动限扭分别何时出现。输出应能用于选定补测项目、比较机构方案和复核实机表现。

前置工作包括第一阶段的证据表、参数表和工况定义，以及 Windows E 盘项目级环境的落球测试。目标机型、实际机构和本机试验数据仍待确认。见[项目现状](../README.md)及[数据缺口](基准工况与数据缺口.md)。

## 范围

- **工程原型**采用独立的通用差速底盘参数，包含自由机身、左右驱动轮、从动支撑和可简化的被动悬挂。先用解析碰撞几何表示轮胎、底盘、平地和硬质单级台阶，以限扭驱动复现接近和爬升。假设值记录来源和取值理由，可用于模型调试及敏感性分析。
- **目标机型**根据本机 CAD 和轮组形式更新几何、质量与惯量、悬挂、驱动约束及轮地接触。收到实测数据后，使用独立数据标定和验证。若实机采用主动抬升，再按其执行机构和控制时序扩展模型。
- 首轮工况包括平地对照、正向台阶和斜向台阶。台阶后的平台长度足够让整机登上并恢复前进。软地毯、多级台阶、导航和强化学习控制在后续立项时评估。

## 功能需求与验收

| 编号 | 需求 | 验收 |
| --- | --- | --- |
| R1 | 受版本管理的 MJCF 模型、工况配置、无界面批运行入口 | Windows 项目级 Python 能运行同一入口。输出记录提交 SHA、模型与配置、参数来源、依赖版本、时间步、求解器、摩擦锥和随机种子（如使用） |
| R2 | 平地、正向和斜向三类工况 | 工况可设置台阶高度与棱边几何、左右入射方向、入射角、接近速度、驱动与摩擦。角度以沿台阶上升方向的前缘法线为 0°。至少保留一个通过和一个预期受阻的原型回归算例 |
| R3 | 越障判定及诊断 | 通过要求整机越过前缘、登上上平台并在配置的时间窗口内恢复前进。单独记录左右接触顺序、纵横向打滑、托底、悬挂触底、限扭和超时，并保留失败分类及其触发阈值。短暂离地或打滑单独作为诊断，正式判退条件与试验口径一起冻结 |
| R4 | 时程与结果归档 | 导出时间、车体位置和姿态、左右轮速和实际关节驱动力矩、悬挂行程及轮地接触力。接触力使用 `mj_contactForce`，注明坐标系和正方向。生成单工况判定与批次摘要，原始运行产物存 Windows 项目 `outputs/` |
| R5 | 可复现与数值检查 | 固定配置重复两次，判定一致且关键结果在声明的复现误差内。代表性工况用 2、1、0.5 ms 对照，检查判定、爬升耗时、姿态和接触峰值的变化。工况接近通过边界或峰值未收敛时在结果中标记，不用单次结果声明通过极限 |
| R6 | 本机标定与独立验证 | 本机基本几何、质量属性、悬挂和驱动约束都有可追溯输入。先用平地和轮组测试标定，再用留出的正向和斜向数据比较通过结果、爬升时间、俯仰/横滚峰值和接触时序。误差限在查看验证结果前根据测量重复性和工程目标确定。报告附实测条件和误差，缺少验证数据时状态记为“待验证” |

## 文献调研路线

| 优先级 | 检索与提取内容 | 起点及适用范围 |
| --- | --- | --- |
| 高 | 扫地机器人越障机构、门槛测试、轮端扭矩、轮胎挠度。查专利全文、厂商原始资料、标准样本与出版方论文。 | [单轮及小型轮式机器人台阶动力学](https://www.hmc.edu/lair/publications/2007/wilhelm_iros_2007.pdf)可追踪轮胎弹性与扭矩的实验对照。[第一阶段证据表](检索日志与证据表.md)已有机构和标准线索 |
| 高 | arXiv 搜索 `wheel step climbing torque friction`、`wheeled-legged stair climbing`、`wheel terrain traction estimation`。提取台阶几何、接触时序、载荷和滑移观测、实机对照方法。 | [轮腿机器人盲爬台阶](https://arxiv.org/abs/2402.06143)有实机台阶试验。[WayFAST](https://arxiv.org/abs/2203.12071)有轮式车辆牵引估计方法。机构尺寸和场景差异需记录 |
| 中 | arXiv 搜索 `MuJoCo system identification locomotion`、`sim-to-real contact calibration`。提取参数辨识、扰动测试和仿真到实机验证流程。 | [MuJoCo 系统辨识](https://arxiv.org/abs/2508.04696)可参考如何用轨迹和控制信号拟合模型。[MuJoCo Playground](https://arxiv.org/abs/2502.08844)可参考仿真环境和迁移评估的组织方式 |

以上为已定位的检索种子。后续精读记录正文页码、图表、模型与试验条件、数据能否复现，以及可迁移到本项目的具体假设、观测量或校核步骤。竞品数据、其他机器人参数和项目假设都保留各自的来源标签。
