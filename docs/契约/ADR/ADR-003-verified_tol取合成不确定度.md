# ADR-003：verified_tol 取合成不确定度

- 状态：已采纳（契约 v1.2，`7658ffb`）
- 背景：试验方案原口径是 `T = 3σ(纯重复性)` 作判定容差。但纯重复性在同一人同一装夹下可以极小，判定门随之收窄到接近 0，等于把「温度、零点、装夹、批次都没变」这个没写下来的前提藏进容差；换天复测即判超限，门比尺子还窄。
- 选项：① 纯重复性 3σ；② 含 B 类的合成不确定度 `k·u_c`。
- 选择：②。`verified_tol = k·u_c`，`u_c = √(u_A² + u_B²)`；`u_A = √(s_r² + s_f² + s_day²)` 三项缺一不可（`s_day` = ≥3 个不同日/批的参考件复测）；`k` 默认 2，`ν_eff < 10` 用 `t` 因子；纯重复性 3σ 降为 `diag_3sigma_A`，只作过程能力诊断、不进判定分支。
- 代价：`u_B` 分量清单从备注变成交付物，标定工作量上升；`k=2` 比 3σ 严，第一批超差条目会变多（预期内，不据此放大 k）。
- 翻案条件：某参数经核 `u_B < 0.1·u_A` 且不可采样项确实为空，可**逐参数**改用纯 A 类 `k=3`；不设全局例外。
- 关联：契约 §6.1、§6.2、S18。
