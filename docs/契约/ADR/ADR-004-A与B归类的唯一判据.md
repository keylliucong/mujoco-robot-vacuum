# ADR-004：A/B 归类的唯一判据

- 状态：已采纳（契约 v1.2，`7658ffb`）
- 背景：装夹差异既被写成"不并入 3σ 的系统项"，又被写成 `s_f` 的一项——同一批数据两处算，容差虚大；用"是否系统项"作归类依据必然反复打架。
- 选项：① 按"系统项 vs 随机项"分；② 按「能否按真实过程重复采样」分。
- 选择：②。**能按真实过程采样 → A 类；采不到只能评估 → B 类。** 装夹能按真实过程重复 → `s_f`；仅当必须外挂/拆解/改变受力路径时 → `u_B,mounting`，两者互斥、同一 `param_id` 只准出现一个。轮胎压缩：空/满载两态各态 `s_r` 独立计算，**两态之差不得并进 `s_r`**（那是口径差异不是重复性），只有覆盖不到的真实载荷谱差异进 `u_B,tire`。
- 代价：`s_day` 要跨日测 ≥3 批，周期变长。
- 翻案条件：无——这是定义层面的归类判据，不是阈值。
- 关联：契约 §6.3、S19。
