# ADR-010：契约冻结与裁定落盘

- 状态：已采纳（2026-11-21，冻结于 v1.7 `30faa2d`，澄清到 v1.7.1 `5ab2d0c`）
- 背景：一晚从 v1.0 升到 v1.7 而 G2 零实现，说明裁定的**输入还在流动**，不是契约在变好；没被实现验证过的条文只能算需求记录。同时裁定只活在某个 bot 的私有记忆里，人看不到、也留不下来。
- 选项：① 继续按需升版；② 设冻结点 + 裁定全部落成仓库内 ADR。
- 选择：②。冻结点 = v1.7 判据集；1.7.x 只收**澄清**（不改判据）与**删规则**（承认过度约束），**不加能力、枚举、列、字段**。开版只允许三种触发：实现期证明某条不可实现/自相矛盾、backlog 条目触发条件已满足、P0 实测推翻现行假定。**backlog 每条必须带触发条件**，没写触发条件的条目等于许愿，不收。裁定一律落成 `docs/契约/ADR/` 下的文件，bot 记忆只留指针。
- 代价：想改就得等数据，短期会不舒服；ADR 维护成本落在裁定人身上。
- 翻案条件：G2 首轮跑完后一次性适配，届时重新评估是否需要解冻一段时间。
- 关联：PR #5、契约 §变更记录。
