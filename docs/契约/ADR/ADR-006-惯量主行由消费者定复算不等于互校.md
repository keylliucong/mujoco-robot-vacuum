# ADR-006：惯量主行由消费者定，复算不等于互校

- 状态：已采纳（契约 v1.5，`a972cee`）
- 背景：同一惯量可以有多个参考点版本（质心 / B 原点），谁主谁辅若由测法定，换一次工装就要改契约；另一方面"同一组数换参考点得到第二行，再互相比对"是恒真式，却会被当成验过了。
- 选项：① 测法决定主行；② 消费者决定主行；③ 两行都当证据。
- 选择：②+否 ③。`chassis/inertial.fullinertia` 读的是关于**质心**的张量 → `ref_point=body_CoM` 为主行（`role=primary`）；`B_origin` 行只作互校（`role=check`），不得被模型或 judge 引用。**同源换参考点 = 复算**（`role=derived`、须 `derived_from` 与 `original_file`），只能抓算术错误、**不得计入 cross-check**；**互校 = 独立来源**（不得有 `derived_from`、须有自己独立的 `original_file`）。换算输入（`m_b`、`r_to_ref`）只准 `derived_from` 引用已有 `m`/`com` 行，不得把数值抄进 `ref`。
- 代价：派生行与互校行在台账里占多行；工装要做成"能独立测两次"才谈得上互校。
- 翻案条件：若某量的两种测法在物理上不可独立（同一台仪器唯一通路），则该量放弃互校、只留单行，并在报告写"无独立校核"。
- 关联：契约 §4、S21、抽查 14。
