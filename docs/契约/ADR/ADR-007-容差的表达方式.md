# ADR-007：容差的表达方式

- 状态：已采纳（契约 v1.6 `0e288d5` + v1.7 `30faa2d` + v1.7.1 `5ab2d0c`）
- 背景：三处会咬人的表达问题——① 台账里 `3%` 与 `3 g` 长得一样，读的人分不清、脚本没法比；② 惯量积接近零，相对容差分母趋零，百分比爆到几百个百分点、没有信息量；③ `u_ref` 只记工装对齐一项，漏掉"参考点→质心"那段，把 4% 算成 0.8%。
- 选项：① 容差混用相对/绝对；② 一律绝对量 + 近零量禁相对 + `u_ref` 按换算链合成。
- 选择：②。`verified_tol` 一律绝对量、与同行 `value` 同单位，百分比只进验收限目标值；近零量（惯量积、横向偏置）用绝对口径，「按对称设 0」标【工程假设】不得标本机实测；`u_ref` 是**各段位移不确定度的合成**，不是工装对齐一项。**自洽优先于目标值**：预算算出与目标不自洽时以预算为准并改目标，不许挑小的写。契约只给配对式 `u_r ≤ ε·r/2`，不给 `ε`。
- 代价：每条相对目标都要换成绝对值落到台账；`u_ref` 要逐段列。
- 翻案条件（v1.7.1 的教训）：`u_com ≤ 0.75 mm` 只在「固定参考点测后换算（≈50 mm）」这一支成立。**缺省走「过质心测法」**（轴过质心、`d ≤ 5 mm`，平行轴项 ≈1%，已交 com 数据不动）。若将来出现无法把轴摆到质心附近的形态，才回到换算支。
- 关联：契约 §6.1.1、S18。
