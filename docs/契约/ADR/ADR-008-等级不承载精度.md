# ADR-008：等级不承载精度

- 状态：已采纳（契约 v1.5，`a972cee`）
- 背景：差分法测附加惯量的相对不确定度可达 25%，但它仍是【本机实测】。若因此把等级压到 `sensitivity`，是把"来源有多硬"和"数字有多准"混成一个旋钮，最后两个都不可信。
- 选项：① 用不确定度大小压等级；② 等级只答来源，精度由 `verified_tol` 答。
- 选择：②。引用 `quantitative` 的报告**必须同时给出该参数的 `verified_tol`**；容差大到让结论在用途上失去意义的，写进用途限制或未覆盖项，不在等级上打折。
- 代价：报告要多写一列；读者可能仍把 `quantitative` 读成"很准"，靠措辞纪律挡。
- 翻案条件：若出现"必须用一个数字概括可信度"的外部要求（如认证），可另加一个派生指标，但不改 `conclusion_level` 的语义。
- 关联：契约 §4、S18。
