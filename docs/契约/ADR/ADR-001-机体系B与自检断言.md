# ADR-001：机体系B与自检断言

- 状态：已采纳（契约 v1.1，`2094934`）
- 背景：CAD 全局系、world 系、chassis 局部系三套并存时，几何、位姿、接触力各自换算，方向错一次不会报错，只会让通过高度与接触力静默偏掉；而这类偏差在外观与步态上都看不出来。
- 选项：① 保留三套系，靠文档约定换算；② 只留 B 系（B ≡ world ≡ `chassis` 局部系），CAD 只推导一次。
- 选择：②。原点 O = 左右驱动轮轴心连线中点在地面的投影，`+x` 前、`+y` 左、`+z` 上；`chassis` 在 world 中恒为单位位姿；台阶注入、位姿输出、接触力分量全在这一套系里。正方向一次定死（两轮 hinge 轴 `+y`，输出列「前进为正」：`wheel_*_speed_radps = -qvel`、`wheel_*_torque_nm = -actuator_force`）。
- 代价：viewer 里看不到 CAD 系参考；换机身时 CAD 换算要重做一次（一次性）。
- 代价：A1–A5 断言必须在 G2 交付时逐条过（质量之和 / CoM / 惯量搬移 / 轮心对称 / 基准位姿）。
- 翻案条件：若将来出现"机身相对底盘可转动"的形态（关节式机身），chassis 不能再等于 world，此 ADR 作废，需引入第四套并重定义输出。
- 关联：契约 §1.1、S16、抽查 9。
