# ADR-002：图纸推算标签与逐行放行

- 状态：已采纳（契约 v1.1，`2094934`）
- 背景：CAD 到达后，大量数值可以从图纸推出来但没实测。若一律记【工程假设】，会浪费图纸信息；若一律当实测，定量结论就建在没称过的质量上。
- 选项：① 不设该标签，CAD 值一律【工程假设】；② 设第 6 标签【图纸推算】，默认止于 `sensitivity`，要进 `quantitative` 必须逐行有实测交叉校核且 `|verified_delta| ≤ verified_tol`。
- 选择：②。**不做「图纸推算 ≈ 实测」的整体等价**：CAD 的几何可信度高、质量与惯量可信度低（漏件、胶水、电池、线束），只能逐行放行；超限的行追加 `cross_check_failed`。
- 代价：台账列从 8 扩到 9（加 `verified_tol`）；交叉校核成了 G2 之后的固定工作量。
- 翻案条件：若某类量被证明"图纸与实测系统性一致"（同一型号多次复现），可对该类量整体放行——但需要数据支撑，不能靠判断。
- 关联：契约 §4、§1.1 `frame.cad_to_B`、S17。
