# ADR-009：裁定归属边界

- 状态：已采纳（多轮裁定归纳，v1.3 起）
- 背景：反复出现"这条要不要进契约"的争论（未覆盖项、命名升档、准静态四条门槛、近似声明、结论适用范围）。每进一条，后面每加一个适用条件都要动契约——这正是"口子开错"。
- 选项：① 全部进契约，集中管理；② 按"是不是数据形状/推导/输出"划线。
- 选择：②。契约管：数据形状（台账、预算表、目录）、推导规则（等级、容差）、输出契约、扩展点。不进契约：方法有效性条件（准静态四条）、适用范围与未覆盖项、近似声明、命名升档门槛——这些归验收限与 G6 图注。
- 代价：契约不再是唯一文档，验收限必须写得足够具体，否则"参数合法但结论被误读"没有兜底。
- 翻案条件：若某类方法条件开始影响等级推导（例如"斜向有效性"需要按工况分支），它就变成了推导规则，那时必须进契约并开版。
- 关联：契约 §4/§6 与 `docs/试验/验收限冻结-<日期>.md` 的分工。
