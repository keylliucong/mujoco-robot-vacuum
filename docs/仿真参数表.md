## 6. 首版模型的最小可运行集合

若短期拿不到本机数据，首版只应包含下列已登记项，其余用参数扫描覆盖：

- 已确定：门槛几何（IEC 62849 三种形状）、测试床与环境条件、MuJoCo 求解器起步参数、接触参数区间。
- 必须补测才能闭环：整机质量与质心、轮半径与轮距、悬挂形式与刚度、轮端扭矩上限、轮-地/轮-门槛摩擦。
- 不能缺省的判据来源：D1/D9 的法向力为正、牵引/法向 < μ；D2/D3 的 h 与 R 比值。
