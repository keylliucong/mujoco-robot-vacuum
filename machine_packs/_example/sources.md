# 示例机型的数据来源

`example_robot` 是虚构的两驱轮刚性底盘，用于演示填表及校验。空载配置 `empty_demo` 包含机身、两个驱动轮和后支撑球。底盘通过刚性连接安装各轮，无悬挂，未开展越障试验。

## 几何与驱动

- 尺寸和关节位置均为工程假设，原始数字写在 [robot.urdf](robot.urdf)。B 原点在两驱轮轴心连线中点的地面投影，+x 向前、+y 向左、+z 向上。URDF 的 `body` 局部坐标系与 B 重合。
- 轮半径按 URDF 中圆柱形碰撞轮胎取值，轮端扭矩上限为演示填写而设。两轮转速上限缺失，实际机型可查轮端规格或实测。
- `rear_support` 用球体近似球形万向支撑，`support_mount` 将球心固定在 B 系坐标 `(-0.12, 0, 0.01)` m。支撑位置直接引用该 link 原点。示例几何未模拟球体滚动。
- 本示例没有 STEP、实测记录或标准验收输入。

## 质量属性

[params.json](params.json) 的整机质量为各 link 质量之和，整机质心为各 link 质心在 B 中按质量加权的平均值。各 link 惯量先按 B 轴表达，再用平行轴定理移到整机质心求和。所有输入均为虚构样件的工程假设。
